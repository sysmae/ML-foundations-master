# Part 1: 벡터 기초

## 📚 벡터란 무엇인가?

**벡터(Vector)**는 **수의 1차원 배열**입니다.

### 표기법

| 표기  | 의미                  | 스타일     |
| ----- | --------------------- | ---------- |
| **x** | 벡터 전체             | **볼드체** |
| $x_2$ | 두 번째 요소 (스칼라) | _이탤릭체_ |

### 핵심 특성

- **순서가 있음**: 각 요소는 특정 위치(position)를 가짐
- **인덱스로 접근**: 각 요소에 색인으로 접근 가능

---

## 🗺️ 벡터 = 공간의 좌표

| 벡터 크기 | 공간       | 예시           |
| --------- | ---------- | -------------- |
| 2         | 2D 평면    | (12, 4)        |
| 3         | 3D 큐브    | (x, y, z)      |
| n         | n차원 공간 | $\mathbb{R}^n$ |

> 💡 n차원은 시각화가 어렵지만, 컴퓨터가 대신 처리해줍니다!

---

## 🔄 벡터 전치 (Vector Transposition)

벡터로 아주 자주 수행하는 연산 중 하나입니다!

### 표기법

윗첨자에 대문자 **T**를 써서 표기:

$$
\mathbf{x}^T
$$

### 의미: 행벡터 ↔ 열벡터 상호 변환

전치는 벡터를 **행에서 열로**, 또는 **열에서 행으로** 변형합니다.

**핵심 포인트**:

- 벡터 내 **모든 요소는 변함없이** 유지
- **순서도 그대로** 유지
- 바뀌는 것은 오직 **차원(shape)** 뿐!

### 시각적 예시

**행벡터** (1행 3열):

$$
\mathbf{x} = \begin{bmatrix} 25 & 2 & 5 \end{bmatrix}
\quad \text{shape: } (1, 3)
$$

**전치 → 열벡터** (3행 1열):

$$
\mathbf{x}^T = \begin{bmatrix} 25 \\ 2 \\ 5 \end{bmatrix}
\quad \text{shape: } (3, 1)
$$

> 📝 **차원 표기 순서**: 행렬에서는 항상 "**행 × 열**" 순서로 표기합니다.  
> (1, 3) = 1행 3열 / (3, 1) = 3행 1열

### 전치의 전치 = 원래 벡터

전치를 두 번 하면 원래 벡터로 돌아옵니다:

$$
(\mathbf{x}^T)^T = \mathbf{x}
$$

---

### ⚠️ NumPy에서 주의할 점!

#### ❌ 1차원 배열은 전치해도 변화 없음!

```python
import numpy as np

# 단일 대괄호로 생성 = 1차원 배열
x = np.array([25, 2, 5])
print(x.shape)    # (3,) — 1차원!

# 전치 시도
x_t = x.T
print(x_t.shape)  # (3,) — 그대로! 변화 없음!
print(x_t)        # [25  2  5]
```

**이유**: 1차원 배열은 "행"도 "열"도 아닌 **단순한 1D 시퀀스**입니다.  
전치할 **두 번째 차원 자체가 없기 때문**에 아무 효과가 없습니다!

#### ✅ 해결책: 이중 대괄호로 2차원 배열 생성

```python
# 이중 대괄호 = 2차원 배열 (행렬 스타일)
y = np.array([[25, 2, 5]])
print(y.shape)    # (1, 3) — 1행 3열

# 이제 전치가 제대로 작동!
y_t = y.T
print(y_t.shape)  # (3, 1) — 3행 1열
print(y_t)
# [[25]
#  [ 2]
#  [ 5]]
```

#### 전치의 전치 확인

```python
# 다시 전치하면 원래 행벡터로 복원
y_original = y_t.T
print(y_original.shape)  # (1, 3) — 원래대로!
print(y_original)        # [[25  2  5]]
```

---

### 왜 전치가 중요할까?

행렬 연산에서 **차원을 맞춰야 할 때** 필수적으로 사용됩니다:

| 연산     | 차원 조합       | 결과          |
| -------- | --------------- | ------------- |
| **내적** | (1, n) × (n, 1) | 스칼라 (1, 1) |
| **외적** | (n, 1) × (1, m) | 행렬 (n, m)   |

예시:

```python
a = np.array([[1, 2, 3]])  # (1, 3) 행벡터
b = np.array([[4], [5], [6]])  # (3, 1) 열벡터

# 내적: (1,3) @ (3,1) = (1,1) 스칼라
dot = a @ b
print(dot)  # [[32]]
```

> 💡 후에 **행렬 곱셈** 섹션에서 이 개념을 더 자세히 다룹니다!

# Part 2: 노름(Norm) — 벡터의 규모

## 🎯 규모와 방향

이전 영상에서 벡터가 **공간 내 좌표**를 표현한다고 배웠습니다.

**같은 벡터**가 **원점(0,0)으로부터의 규모(magnitude)와 방향(direction)**도 표현합니다!

$$
\mathbf{x} = \begin{bmatrix} 12 \\ 4 \end{bmatrix}
$$

- **좌표 해석**: 2D 공간의 점 (12, 4)
- **벡터 해석**: 원점 (0,0)에서 (12,4)까지의 화살표

---

## 📏 노름(Norm)이란?

**노름(Norm)**은 벡터의 **규모(크기)**를 수량화하는 함수입니다.

---

## 🔷 L² 노름 (유클리드 노름) — 가장 중요!

### 공식

$$
\|\mathbf{x}\|_2 = \sqrt{\sum_{i} x_i^2} = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}
$$

### 의미

- **유클리드 거리(Euclidean distance)**: 원점부터의 "직선 거리"
- 실생활에서 자나 줄자로 재는 거리와 동일!

### 표기법

$$
\|\mathbf{x}\|_2 \quad \text{또는} \quad \|\mathbf{x}\| \quad \text{(아래첨자 생략 시 L²)}
$$

> 💡 **머신러닝에서 가장 흔히 사용**되어, 아래첨자 2를 생략해도 L² 노름을 의미합니다.

### 코드 예제

```python
import numpy as np

x = np.array([25, 2, 5])

# 방법 1: 직접 계산
norm_manual = np.sqrt(np.sum(x**2))
print(norm_manual)  # 25.573...

# 방법 2: NumPy 내장 함수 (권장)
norm = np.linalg.norm(x)
print(norm)  # 25.573...
```

> 📝 만약 3차원 공간의 단위가 **미터**라면, 벡터 x는 원점에서 **25.6m** 떨어진 지점을 가리킵니다.

---

## ⭐ 단위벡터 (Unit Vector)

**L² 노름이 1인 벡터**를 단위벡터라고 합니다.

$$
\|\mathbf{u}\|_2 = 1
$$

### 단위벡터 만들기

```python
x = np.array([3, 4])
norm = np.linalg.norm(x)  # 5.0

unit_x = x / norm
print(unit_x)  # [0.6, 0.8]
print(np.linalg.norm(unit_x))  # 1.0
```

---

## 📐 L¹ 노름 (맨해튼 거리)

### 공식

$$
\|\mathbf{x}\|_1 = \sum_{i} |x_i| = |x_1| + |x_2| + \cdots + |x_n|
$$

### 특성

- 각 요소의 **절대값의 합**
- **0과 0이 아닌 값**의 구별이 중요할 때 사용
- 원점에서의 거리에 따라 **선형적**으로 증가

### 코드 예제

```python
x = np.array([25, 2, 5])

l1_norm = np.sum(np.abs(x))
print(l1_norm)  # 32
```

> 💡 **같은 벡터**도 노름 종류에 따라 **다른 크기**를 가집니다:
>
> - L² 노름: 25.57
> - L¹ 노름: 32

---

## 🔶 제곱 L² 노름 (Squared L² Norm)

### 공식

$$
\|\mathbf{x}\|_2^2 = \sum_{i} x_i^2 = \mathbf{x}^T \mathbf{x}
$$

### 특성

- L² 노름에서 **제곱근을 생략**
- **연산 비용이 저렴** (루트 계산 불필요)
- **도함수 계산이 간단**: 요소 하나의 미분은 그 요소 하나만 필요

### 단점

- 0 근처에서 **천천히 증가** → 0과 0에 가까운 값 구별이 어려움

### 코드 예제

```python
x = np.array([25, 2, 5])

# 방법 1: 직접 계산
sq_l2 = np.sum(x**2)
print(sq_l2)  # 654

# 방법 2: 내적 (x^T @ x)
sq_l2 = np.dot(x, x)
print(sq_l2)  # 654
```

---

## 🔺 Max 노름 (무한대 노름)

### 공식

$$
\|\mathbf{x}\|_\infty = \max_i |x_i|
$$

### 의미

- 요소들의 절대값 중 **최댓값**

### 코드 예제

```python
x = np.array([25, 2, 5])

max_norm = np.max(np.abs(x))
print(max_norm)  # 25
```

---

## 📊 노름 비교 정리

| 노름        | 공식                | 벡터 [25, 2, 5] 결과 | 용도                |
| ----------- | ------------------- | -------------------- | ------------------- |
| **L²**      | $\sqrt{\sum x_i^2}$ | 25.57                | 일반적 거리, 정규화 |
| **L¹**      | $\sum \|x_i\|$      | 32                   | 희소성, 0 구별      |
| **제곱 L²** | $\sum x_i^2$        | 654                  | 저비용 연산, 미분   |
| **Max**     | $\max \|x_i\|$      | 25                   | 최대 오차 제한      |

---

## 🧮 일반화: Lᵖ 노름

모든 노름은 **Lᵖ 노름**의 특수한 경우입니다:

$$
\|\mathbf{x}\|_p = \left( \sum_{i} |x_i|^p \right)^{1/p}
$$

**조건**: $p \geq 1$ (실수)

| p 값  | 노름     |
| ----- | -------- |
| p = 1 | L¹ 노름  |
| p = 2 | L² 노름  |
| p → ∞ | Max 노름 |

---

## 🤖 머신러닝에서의 활용

**L1, L2 규제(Regularization)**:

- 회귀 모델에서 과적합 방지
- **L1 규제 (Lasso)**: 희소한 가중치 유도
- **L2 규제 (Ridge)**: 가중치 크기 제한

> 💡 "L1, L2 regularization"이라는 용어에서 L1, L2가 바로 이 노름을 의미합니다!
