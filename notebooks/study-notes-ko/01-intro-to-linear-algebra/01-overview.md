# 1. 개요: 선형대수란?

## 📌 핵심 질문

> "고차원 공간에서 미지수를 어떻게 풀 것인가?"

---

## 🔷 정의

**선형대수(Linear Algebra)** = 벡터와 행렬로 선형 방정식을 푸는 수학

---

## 🏠 예시: 도둑과 보안관

```
도둑: d = 2.5t      (속도 2.5km/분)
보안관: d = 3(t-5)  (5분 후 출발, 속도 3km/분)
```

**문제**: 보안관은 언제 도둑을 잡을까?

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 40, 1000)
d_robber = 2.5 * t
d_sheriff = 3 * (t - 5)

plt.plot(t, d_robber, label='도둑')
plt.plot(t, d_sheriff, label='보안관')
plt.axvline(x=30, linestyle='--')
plt.legend()
plt.show()
```

**정답**: t=30분, d=75km 지점에서 체포!
