# 4. 행렬 (Matrix)

## 📌 정의

**행렬** = 수의 2차원 배열 = **Rank 2 텐서**

> "벡터(선)를 층층이 쌓아 만든 면(Surface)"

---

## 📐 구조

- **행(Row)**: 가로 줄 (좌 → 우)
- **열(Column)**: 세로 줄 (위 → 아래)
- **크기**: [행, 열] 순서로 표기

$$
\mathbf{X} = \begin{bmatrix} 25 & 2 \\ 5 & 26 \\ 3 & 7 \end{bmatrix}
\quad \text{Shape: } [3, 2] \text{ (3행 2열)}
$$

---

## ✏️ 표기법

| 대상      | 표기                      | 예시         |
| --------- | ------------------------- | ------------ |
| 행렬 전체 | 대문자, 볼드, 이탤릭      | $\mathbf{X}$ |
| 개별 원소 | 대문자, 이탤릭 + 아래첨자 | $X_{i,j}$    |
| i행 전체  | 콜론 사용                 | $X_{i,:}$    |
| j열 전체  | 콜론 사용                 | $X_{:,j}$    |

> ⚠️ 수학: 1부터 시작 / Python: **0부터 시작!**

| 구분         | 수학      | Python    |
| ------------ | --------- | --------- |
| 첫 번째 원소 | $X_{1,1}$ | `X[0, 0]` |
| 3행 2열 원소 | $X_{3,2}$ | `X[2, 1]` |

---

## 🐍 NumPy로 생성

```python
import numpy as np

# 중첩 대괄호로 생성 (바깥=행, 안쪽=원소)
X = np.array([[25, 2],
              [5, 26],
              [3, 7]])

print(X.shape)  # (3, 2) → 3행 2열
print(X.size)   # 6 → 총 원소 개수 (3×2)
```

---

## 🔪 슬라이싱 (Slicing)

콜론(`:`)은 "해당 축의 모든 것"을 의미

```python
# 첫 번째 열 전체 (왼쪽 열)
print(X[:, 0])   # [25, 5, 3]

# 두 번째 행 전체 (가운데 행)
print(X[1, :])   # [5, 26]

# 범위 지정: 처음 2행, 처음 2열
print(X[0:2, 0:2])
# [[25,  2]
#  [ 5, 26]]
```

---

## 🔄 행렬 전치

행 ↔ 열 교환: $X_{i,j}^T = X_{j,i}$

```python
print(X.shape)    # (3, 2)
print(X.T.shape)  # (2, 3)
```

---

## 🔥 PyTorch

```python
import torch

X_pt = torch.tensor([[25, 2],
                     [5, 26],
                     [3, 7]])

print(X_pt.shape)   # torch.Size([3, 2])
print(X_pt[1, :])   # tensor([5, 26])
```

---

## 🧠 TensorFlow

```python
import tensorflow as tf

X_tf = tf.Variable([[25, 2],
                    [5, 26],
                    [3, 7]])

print(tf.rank(X_tf))   # 2 (랭크)
print(tf.shape(X_tf))  # [3, 2] (크기)
print(X_tf[1, :])      # [5, 26]
```

## 🤖 ML에서 행렬의 의미

| 행(Row)              | 열(Column)       |
| -------------------- | ---------------- |
| 개별 데이터 샘플     | 특징(Feature)    |
| 사람 1명, 이미지 1장 | 키, 몸무게, 나이 |

예: 3×2 행렬 = "3명의 사람에 대한 2가지 특징 데이터"

---

## 📊 특수 행렬 (미리보기)

| 종류              | 특징               | 생성               |
| ----------------- | ------------------ | ------------------ |
| **단위 행렬 (I)** | 대각선 1, 나머지 0 | `np.eye(3)`        |
| **대칭 행렬**     | $X^T = X$          | -                  |
| **대각 행렬**     | 대각선만 값 있음   | `np.diag([1,2,3])` |
| **직교 행렬**     | $X^T X = I$        | -                  |

```python
I = np.eye(3)  # 3×3 단위 행렬
# [[1. 0. 0.]
#  [0. 1. 0.]
#  [0. 0. 1.]]
```
