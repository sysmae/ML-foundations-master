# 8. 기초 텐서 산수 (Basic Tensor Arithmetic)

> Segment 2: 기본 텐서 연산의 일부

## 📌 개요

텐서 산수는 크게 두 가지로 나눌 수 있습니다:

1. **스칼라 연산** - 텐서와 단일 값의 연산
2. **아다마르 곱 (Hadamard Product)** - 같은 크기의 텐서끼리 요소별 연산

---

## 🔢 스칼라 연산 (Scalar Operations)

### 핵심 개념

스칼라로 텐서를 연산하면:

- **텐서의 형태(shape)는 그대로 유지**
- **모든 요소에 동일하게 적용**

```python
import numpy as np

X = np.array([[25,  2],
              [ 5, 26],
              [ 3,  7]])
```

### 스칼라 곱셈

```python
X * 2
# [[50,  4],
#  [10, 52],
#  [ 6, 14]]
```

모든 요소에 2가 곱해집니다!

### 스칼라 덧셈

```python
X + 2
# [[27,  4],
#  [ 7, 28],
#  [ 5,  9]]
```

모든 요소에 2가 더해집니다!

### 복합 연산 (연산 순서 적용)

```python
X * 2 + 2
# [[52,  6],
#  [12, 54],
#  [ 8, 16]]
```

> **수학 연산 순서 적용**: 곱셈이 덧셈보다 먼저!  
> 예: `25 × 2 + 2 = 50 + 2 = 52`

---

## 💻 라이브러리별 스칼라 연산

### NumPy

```python
import numpy as np

X = np.array([[25, 2], [5, 26], [3, 7]])
result = X * 2 + 2
```

### PyTorch

```python
import torch

X_pt = torch.tensor([[25, 2], [5, 26], [3, 7]])
result = X_pt * 2 + 2  # NumPy와 동일!
```

**내부 동작**: `*`와 `+` 연산자가 **오버로드(overload)** 되어  
`torch.mul()`과 `torch.add()` 메서드가 자동 호출됩니다.

### TensorFlow

```python
import tensorflow as tf

X_tf = tf.constant([[25, 2], [5, 26], [3, 7]])
result = X_tf * 2 + 2  # 동일하게 동작!
```

TensorFlow도 마찬가지로 연산자 오버로딩이 적용됩니다.

## ⭐ 아다마르 곱 (Hadamard Product)

### 핵심 개념

> ⚠️ **주의**: 아다마르 곱은 **행렬 곱셈(Matrix Multiplication)이 아닙니다!**

아다마르 곱 = **요소별 곱셈 (Element-wise Product)**

**조건**: 두 텐서의 **차원이 동일**해야 함

### 수학적 표기

$$
A \odot B
$$

원(○) 안에 점(·)이 있는 기호를 사용합니다.

### 예제

```python
import numpy as np

X = np.array([[25,  2],
              [ 5, 26],
              [ 3,  7]])

# X에 2를 더해 A 만들기
A = X + 2
# [[27,  4],
#  [ 7, 28],
#  [ 5,  9]]
```

### 요소별 덧셈

```python
X + A
# [[52,  6],
#  [12, 54],
#  [ 8, 16]]
```

계산 과정:

- `25 + 27 = 52`
- `2 + 4 = 6`
- ... (각 위치의 요소끼리 더함)

### 요소별 곱셈 (아다마르 곱)

```python
X * A
# [[675,   8],
#  [ 35, 728],
#  [ 15,  63]]
```

계산 과정:

- `25 × 27 = 675`
- `2 × 4 = 8`
- `5 × 7 = 35`
- ... (각 위치의 요소끼리 곱함)

---

## 📊 시각적 비교

```
요소별 곱셈 (아다마르 곱):
┌───────┐   ┌───────┐   ┌─────────┐
│ 25  2 │   │ 27  4 │   │ 675   8 │
│  5 26 │ * │  7 28 │ = │  35 728 │
│  3  7 │   │  5  9 │   │  15  63 │
└───────┘   └───────┘   └─────────┘
  (3×2)       (3×2)        (3×2)

→ 같은 위치끼리 곱함!
→ 결과 shape도 동일
```

---

## 💻 라이브러리별 아다마르 곱

### NumPy

```python
X * A  # 간단!
```

### PyTorch

```python
X_pt * A_pt  # NumPy와 동일
```

### TensorFlow

```python
X_tf * A_tf  # 동일하게 동작
```

> 세 라이브러리 모두 `*` 연산자로 아다마르 곱 수행!

---

## ⚠️ 아다마르 곱 vs 행렬 곱

| 구분       | 아다마르 곱      | 행렬 곱             |
| ---------- | ---------------- | ------------------- |
| 표기       | `*` 또는 $\odot$ | `@` 또는 `np.dot()` |
| 조건       | 같은 shape       | 내부 차원 일치      |
| 결과 shape | 동일 유지        | 외부 차원 조합      |
| 연산       | 같은 위치끼리 곱 | 행×열 내적          |

---

## 💡 핵심 정리

1. **스칼라 연산**: 모든 요소에 동일하게 적용, shape 유지
2. **연산 순서**: 수학의 표준 순서 (곱셈 → 덧셈)
3. **연산자 오버로딩**: `*`, `+`, `-`, `/` 모두 라이브러리에서 자동 처리
4. **아다마르 곱**: 같은 위치끼리 곱셈 (행렬 곱 ❌)
5. **필수 조건**: 아다마르 곱은 **동일한 차원**일 때만 가능
