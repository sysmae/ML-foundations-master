# 7. 텐서 전치 (Tensor Transposition)

> Segment 2: 기본 텐서 연산의 일부

## 📌 개요

텐서 전치(Transposition)는 텐서의 축을 교환하는 연산입니다. 간단히 말해, **행과 열을 뒤바꾸는 것**이죠.

---

## 🔢 차원별 전치 규칙

### 스칼라 (0차원 텐서)

스칼라의 전치는 **자기 자신**입니다.

```python
x = 25
# 스칼라는 축이 없으므로 전치해도 그대로!
```

> **왜?** 스칼라는 차원이 없기 때문에 "바꿀 축" 자체가 없습니다.

---

### 벡터 (1차원 텐서)

벡터의 전치는 **행벡터 ↔ 열벡터** 변환입니다.

```python
import numpy as np

# 행벡터 (1×3)
row_vec = np.array([[1, 2, 3]])
print(row_vec.shape)    # (1, 3)

# 전치 → 열벡터 (3×1)
col_vec = row_vec.T
print(col_vec.shape)    # (3, 1)
```

**시각적 표현:**

```
행벡터: [1, 2, 3]  →  열벡터: [1]
                          [2]
                          [3]
```

> ⚠️ **주의**: 1차원 NumPy 배열 `np.array([1, 2, 3])`의 `.T`는 효과가 없습니다!  
> 2차원으로 표현해야 전치가 제대로 작동합니다.

---

### 행렬 (2차원 텐서) ⭐

**행렬 전치가 핵심입니다!** 사실 스칼라와 벡터 전치는 행렬 전치의 특수한 경우일 뿐입니다.

#### 전치의 원리

1. 행렬의 **대각선 주축**을 기준으로 "접는다"
2. 대각선은 **왼쪽 위 → 오른쪽 아래**로 이어짐
3. 원래 **(i행, j열)** 위치의 요소가 **(j행, i열)**로 이동

$$
(X^T)_{ij} = X_{ji}
$$

#### 시각적 이해

```
원본 X (3×2):           전치 X^T (2×3):
┌─────────┐             ┌─────────────┐
│ 25 │  2 │             │ 25 │  5 │ 3 │
├─────────┤     →       ├─────────────┤
│  5 │ 26 │             │  2 │ 26 │ 7 │
├─────────┤             └─────────────┘
│  3 │  7 │
└─────────┘
```

**관찰해보세요:**

- 첫 번째 **열** `[25, 5, 3]` → 첫 번째 **행**이 됨
- 두 번째 **열** `[2, 26, 7]` → 두 번째 **행**이 됨
- 대각선 위의 요소들(25, 26)은 위치가 변하지 않음

## 💻 라이브러리별 구현

### NumPy

```python
import numpy as np

X = np.array([[25,  2],
              [ 5, 26],
              [ 3,  7]])

print(X.shape)    # (3, 2)

# 전치 - 매우 간단!
X_T = X.T

print(X_T.shape)  # (2, 3)
print(X_T)
# [[25  5  3]
#  [ 2 26  7]]
```

---

### PyTorch

PyTorch는 NumPy와 거의 동일합니다:

```python
import torch

X_pt = torch.tensor([[25,  2],
                     [ 5, 26],
                     [ 3,  7]])

# .T 속성 사용
X_pt_T = X_pt.T

print(X_pt_T)
# tensor([[25,  5,  3],
#         [ 2, 26,  7]])
```

---

### TensorFlow

TensorFlow는 조금 더 명시적인 방식을 사용합니다:

```python
import tensorflow as tf

X_tf = tf.constant([[25,  2],
                    [ 5, 26],
                    [ 3,  7]])

# tf.transpose() 함수 사용
X_tf_T = tf.transpose(X_tf)

print(X_tf_T)
# tf.Tensor(
# [[25  5  3]
#  [ 2 26  7]], shape=(2, 3), dtype=int32)
```

---

## 📊 라이브러리 비교 요약

| 라이브러리 | 문법             | 특징                        |
| ---------- | ---------------- | --------------------------- |
| NumPy      | `.T`             | 가장 간단, Pythonic         |
| PyTorch    | `.T`             | NumPy와 동일                |
| TensorFlow | `tf.transpose()` | 함수 형태, 약간의 추가 코드 |

---

## 💡 핵심 정리

1. **전치 = 축 교환** (행 ↔ 열)
2. 행렬 `(m, n)` 전치 → `(n, m)`
3. 원소 위치: $(i, j) \rightarrow (j, i)$
4. **대각선 요소는 위치 불변** (자기 자신과 교환)
5. NumPy/PyTorch에서는 `.T`, TensorFlow에서는 `tf.transpose()`
