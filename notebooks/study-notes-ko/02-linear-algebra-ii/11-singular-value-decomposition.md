## 1️⃣ SVD란?

### 고유값 분해의 한계

**고유값 분해**는 정방행렬($n \times n$)에만 적용 가능했습니다:

$$
A = V \Lambda V^{-1}
$$

하지만 머신러닝에서는 **직사각형 행렬**이 훨씬 흔합니다:

- 이미지: $1000 \times 2000$ 픽셀
- 데이터셋: $10000$ 샘플 × $500$ 특성
- 단어 임베딩: $50000$ 단어 × $300$ 차원

### SVD: 모든 행렬에 적용 가능!

**특이값 분해(SVD)**는 **모든 $m \times n$ 행렬**에 적용할 수 있습니다:

$$
A = U D V^T
$$

여기서:

- $A$: $m \times n$ 행렬 (원본)
- $U$: $m \times m$ 행렬 (**좌특이벡터** 행렬)
- $D$: $m \times n$ 대각행렬 (**특이값** 포함)
- $V^T$: $n \times n$ 행렬 (**우특이벡터**의 전치)

---

## 2️⃣ SVD 구성 요소 이해하기

### 시각적 이해

```
      A          =       U       ×       D       ×      V^T
   (m × n)           (m × m)        (m × n)         (n × n)

┌─────────┐      ┌─────────┐   ┌─────────┐   ┌─────────┐
│         │      │         │   │ σ₁  0   │   │         │
│  원본   │  =   │  좌특이  │ × │  0  σ₂  │ × │  우특이  │
│  행렬   │      │  벡터   │   │  0   0  │   │  벡터ᵀ  │
└─────────┘      └─────────┘   └─────────┘   └─────────┘
```

### 각 구성 요소의 의미

| 구성 요소              | 크기         | 설명                                                            |
| :--------------------- | :----------- | :-------------------------------------------------------------- |
| **$U$ (좌특이벡터)**   | $m \times m$ | 열(column)이 좌특이벡터. 행 공간의 직교 기저.                   |
| **$D$ (특이값)**       | $m \times n$ | 주대각선에 특이값 $\sigma_1, \sigma_2, \dots$ 배치. 나머지는 0. |
| **$V^T$ (우특이벡터)** | $n \times n$ | 행(row)이 우특이벡터. 열 공간의 직교 기저.                      |

### 특이값의 특징

- 특이값 $\sigma_i$는 항상 **0 이상의 실수**
- 관례적으로 **내림차순** 정렬: $\sigma_1 \geq \sigma_2 \geq \dots \geq 0$
- 첫 번째 특이값이 가장 중요한 정보를 담고 있음

## 3️⃣ NumPy로 SVD 구현하기

### 예제: 3×2 직사각형 행렬

```python
import numpy as np

# 3행 2열의 직사각형 행렬 정의
A = np.array([[-1, 2],
              [3, -2],
              [5, 7]])

print(f"행렬 A (shape: {A.shape}):")
print(A)
# 출력:
# [[-1  2]
#  [ 3 -2]
#  [ 5  7]]
```

### np.linalg.svd로 분해하기

```python
# SVD 수행
U, d, Vt = np.linalg.svd(A)

print(f"\n좌특이벡터 U (shape: {U.shape}):")
print(U)
# 출력: 3×3 행렬 (A의 행 수 = 3)

print(f"\n특이값 d (shape: {d.shape}):")
print(d)
# 출력: 길이 2인 벡터 (특이값 2개)
# [9.71..., 3.27...]

print(f"\n우특이벡터 전치 Vt (shape: {Vt.shape}):")
print(Vt)
# 출력: 2×2 행렬 (A의 열 수 = 2)
```

**⚠️ 주의**: `np.linalg.svd`는 특이값을 **벡터 d**로 반환합니다 (대각행렬이 아님!)

### 대각행렬 D 만들기

행렬 곱셈 $A = U D V^T$를 수행하려면, `d` 벡터를 적절한 크기의 **대각행렬 $D$**로 변환해야 합니다.

```python
# 1단계: 특이값으로 정방 대각행렬 생성
D_square = np.diag(d)
print(f"\n정방 대각행렬 (shape: {D_square.shape}):")
print(D_square)
# 출력:
# [[9.71..., 0     ]
#  [0     , 3.27...]]

# 2단계: 행렬 곱셈에 맞는 크기로 조정 (m×n = 3×2)
D = np.zeros((A.shape[0], A.shape[1]))  # 3×2 영행렬
D[:D_square.shape[0], :D_square.shape[1]] = D_square

print(f"\n최종 대각행렬 D (shape: {D.shape}):")
print(D)
# 출력:
# [[9.71..., 0     ]
#  [0     , 3.27...]
#  [0     , 0     ]]  ← 행 추가됨!
```

### 분해 공식 검증: $A = U D V^T$

```python
# U × D × V^T 계산
A_reconstructed = np.dot(U, np.dot(D, Vt))

print(f"\nU × D × Vᵀ:")
print(A_reconstructed)
# 출력:
# [[-1.  2.]
#  [ 3. -2.]
#  [ 5.  7.]]

# 원본과 비교
print(f"\n원본 A와 같은가?: {np.allclose(A, A_reconstructed)}")
# 출력: True ✅
```

### 전체 코드 요약

```python
import numpy as np

# 1. 행렬 정의
A = np.array([[-1, 2], [3, -2], [5, 7]])

# 2. SVD 수행
U, d, Vt = np.linalg.svd(A)

# 3. 대각행렬 D 생성 (크기 맞추기)
D = np.zeros((A.shape[0], A.shape[1]))
np.fill_diagonal(D, d)

# 4. 검증: A = U D V^T
A_check = U @ D @ Vt
print("동일한가?:", np.allclose(A, A_check))  # True
```

## 4️⃣ SVD와 고유값 분해의 관계

### 비교표

| 항목          | 고유값 분해               | 특이값 분해 (SVD)            |
| :------------ | :------------------------ | :--------------------------- |
| **공식**      | $A = V \Lambda V^{-1}$    | $A = U D V^T$                |
| **적용 대상** | 정방행렬 ($n \times n$)만 | **모든 행렬** ($m \times n$) |
| **벡터**      | 고유벡터 1세트            | 좌/우 특이벡터 2세트         |
| **값**        | 고유값 (음수 가능)        | 특이값 (항상 0 이상)         |
| **복소수**    | 복소수 가능               | 항상 실수                    |

### 수학적 연결

SVD와 고유값 분해는 깊이 연결되어 있습니다:

1. **좌특이벡터** $U$의 열 = $A A^T$의 고유벡터
2. **우특이벡터** $V$의 열 = $A^T A$의 고유벡터
3. **특이값** $\sigma_i$ = $\sqrt{\lambda_i}$ (여기서 $\lambda_i$는 $A A^T$ 또는 $A^T A$의 고유값)

```python
# 관계 검증
A = np.array([[-1, 2], [3, -2], [5, 7]])
U, d, Vt = np.linalg.svd(A)

# A A^T의 고유값/고유벡터
AAt = A @ A.T
eigenvalues_AAt, eigenvectors_AAt = np.linalg.eig(AAt)

print("특이값의 제곱:", d**2)
print("A A^T의 고유값:", np.sort(eigenvalues_AAt)[::-1])
# 두 값이 (정렬 후) 일치!
```

## 5️⃣ SVD의 기하학적 의미

SVD는 행렬 변환을 **3단계**로 분해합니다:

1. **$V^T$: 회전** — 입력 공간에서 데이터를 정렬
2. **$D$: 스케일링** — 각 축을 특이값만큼 늘이거나 줄임
3. **$U$: 회전** — 출력 공간에서 데이터를 최종 위치로 회전

$$
\text{변환} = \text{회전} \rightarrow \text{스케일링} \rightarrow \text{회전}
$$

**핵심 통찰**: 어떤 선형 변환이든 회전과 스케일링의 조합으로 분해할 수 있습니다!

## 🎯 요약

### 핵심 공식

$$
A_{m \times n} = U_{m \times m} \cdot D_{m \times n} \cdot V^T_{n \times n}
$$

### 핵심 포인트

| 개념                     | 설명                                                                       |
| :----------------------- | :------------------------------------------------------------------------- |
| **적용 범위**            | 모든 $m \times n$ 행렬 (직사각형 포함!)                                    |
| **좌특이벡터 $U$**       | $m \times m$ 직교행렬, 열이 좌특이벡터                                     |
| **특이값 $D$**           | $m \times n$ 대각행렬, 대각선에 $\sigma_1 \geq \sigma_2 \geq \dots \geq 0$ |
| **우특이벡터 $V^T$**     | $n \times n$ 직교행렬, 행이 우특이벡터                                     |
| **고유값 분해와의 관계** | 특이값 = $\sqrt{\text{고유값}}$, 특이벡터 = 고유벡터                       |
