# 8. 행렬식과 고유값의 관계 (Determinants and Eigenvalues)

> **"행렬식은 모든 고유값의 곱과 같다"** — 이 단순한 공식이 선형대수학의 핵심 연결고리입니다.

행렬 성질의 핵심인 행렬식(Determinant)과 고유값(Eigenvalue)은 서로 동떨어진 개념이 아닙니다. 이 둘 사이에는 놀라울 정도로 단순하고 강력한 관계가 존재하며, 이를 통해 행렬이 공간에 미치는 영향을 직관적으로 이해할 수 있습니다.

영상에서 "계수"라고 표현된 부분은 문맥상 **행렬식(Determinant)**을 의미합니다. 이 수치는 단순한 계산 결과가 아니라, 행렬이 공간을 얼마나 확장하거나 축소하는지를 보여주는 **'공간 변환의 척도'**입니다.

---

## 1️⃣ 핵심 관계식

어떤 $n \times n$ 정방행렬 $X$의 행렬식은 $X$의 모든 고유값($\lambda_1, \lambda_2, \dots, \lambda_n$)의 곱과 같습니다.

$$
\det(X) = \prod_{i=1}^{n} \lambda_i = \lambda_1 \times \lambda_2 \times \dots \times \lambda_n
$$

### 왜 이게 성립할까요?

이 관계를 직관적으로 이해해 봅시다:

1. **고유값의 의미**: 고유값은 각 **축(차원)별로 공간이 얼마나 늘어나거나 줄어드는지**를 나타냅니다.

   - $\lambda = 2$이면 해당 방향으로 2배 늘어남
   - $\lambda = 0.5$이면 해당 방향으로 절반으로 줄어듦
   - $\lambda = 0$이면 해당 차원이 완전히 사라짐 (붕괴)

2. **행렬식의 의미**: 행렬식은 **전체 공간(부피/면적)이 얼마나 변하는지**를 나타냅니다.

   - $\det = 4$이면 면적이 4배로 확장
   - $\det = 0.25$이면 면적이 1/4로 축소
   - $\det = 0$이면 면적이 0 (차원 붕괴)

3. **결론**: 각 축의 변화율(고유값)을 모두 곱하면, 전체 변화율(행렬식)이 됩니다.
   - 예: 가로 2배 × 세로 3배 = 면적 6배

### 코드로 확인하기 (NumPy)

3차원 행렬 예제로 이 공식이 진짜인지 확인해 봅시다.

```python
import numpy as np

# 3x3 행렬 X 정의
X = np.array([[1, 2, 4],
              [2, -1, 3],
              [0, 5, 1]])

# 1. 행렬식(Determinant) 직접 계산
det_X = np.linalg.det(X)
print(f"행렬식: {det_X}")  # 출력: 19.999999999999996 (약 20)

# 2. 고유값(Eigenvalues) 구하기
lambdas, V = np.linalg.eig(X)
print(f"고유값들: {lambdas}")  # 출력: [-3.25599251, -1.13863631, 5.39462882]

# 3. 고유값들의 곱 계산
product_lambdas = np.prod(lambdas)
print(f"고유값의 곱: {product_lambdas}")  # 출력: 19.999999999999996 (약 20)

# ✅ 결과: 두 값이 (부동소수점 오차 범위 내에서) 완벽하게 일치!
# 행렬식 ≈ 20, 고유값의 곱 ≈ 20
```

**해석**: 이 3x3 행렬 $X$를 데이터에 적용하면, 3차원 공간의 부피가 약 **20배** 확장됩니다.

---

## 2️⃣ 기하학적 관점: 부피와 공간 붕괴

행렬식의 절댓값 $|\det(X)|$은 행렬 $X$를 어떤 텐서에 곱했을 때, 그 텐서가 차지하는 **공간의 용량(부피)이 얼마나 변화하는지**를 수량화합니다.

### $|\det(X)|$의 값에 따른 변화

| 값의 범위             | 공간에 미치는 영향 | 설명                                                                    |
| :-------------------- | :----------------- | :---------------------------------------------------------------------- |
| $\|\det(X)\| = 0$     | **공간 붕괴**      | 최소 하나의 차원이 완전히 사라짐 (예: 사각형 → 직선). 역행렬 존재 불가. |
| $0 < \|\det(X)\| < 1$ | **부피 축소**      | 텐서의 용량이 줄어듦.                                                   |
| $\|\det(X)\| = 1$     | **부피 유지**      | 형태는 변해도 전체적인 용량은 그대로 유지됨.                            |
| $\|\det(X)\| > 1$     | **부피 확장**      | 텐서의 용량이 커짐.                                                     |

### 왜 절댓값을 쓸까?

행렬식은 **음수**가 될 수 있습니다. 음수 행렬식은 공간이 **뒤집혔음(Reflection)**을 의미합니다.

- $\det = -4$: 면적이 4배로 늘어났지만, 거울처럼 뒤집힘
- $\det = 4$: 면적이 4배로 늘어남, 방향 유지

따라서 **순수한 부피 변화**만 보려면 절댓값 $|\det|$를 사용합니다.

## 3️⃣ 기저 벡터를 통한 시각적 이해 (4가지 시나리오)

단위 사각형을 형성하는 기저 벡터 행렬 $B = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$에 다양한 행렬을 곱해보며 변화를 관찰해봅시다.

이 단위 사각형은 면적이 1인 정사각형입니다. 행렬을 곱하면 이 정사각형이 어떻게 변형되는지 살펴봅니다.

---

### 3.1 특이 행렬 $N$ — 공간의 붕괴 ($\det = 0$)

$$
N = \begin{bmatrix} -4 & 1 \\ -8 & 2 \end{bmatrix}
$$

```python
import numpy as np

# 특이 행렬 N 정의
N = np.array([[-4, 1], [-8, 2]])

# 행렬식 계산
det_N = np.linalg.det(N)
print(f"행렬식: {det_N}")  # 출력: 0.0

# 고유값 계산
lambdas, V = np.linalg.eig(N)
print(f"고유값들: {lambdas}")  # 출력: [-2., 0.] ← 하나가 0!

# 고유값의 곱
print(f"고유값의 곱: {np.prod(lambdas)}")  # 출력: 0.0

# 역행렬 시도 (에러 발생!)
# np.linalg.inv(N)  # LinAlgError: Singular matrix
```

**왜 행렬식이 0일까?**

행렬 $N$의 열을 자세히 보면:

- 첫 번째 열: $[-4, -8]$
- 두 번째 열: $[1, 2]$

첫 번째 열 = 두 번째 열 × (-4) 입니다! 즉, **열들이 선형 종속(Linearly Dependent)**입니다.

**기하학적 해석**:

- 선형 종속이란, 두 벡터가 같은 방향(또는 정반대 방향)을 가리킨다는 뜻입니다.
- 따라서 2차원 평면의 사각형이 1차원 **직선**으로 찌그러집니다.
- 면적(부피)이 **0**이 됩니다.

**고유값과의 관계**:

- 고유값이 $-2$와 $0$입니다.
- $-2 \times 0 = 0$ → 행렬식도 0

**핵심 포인트**: 고유값 중 하나라도 0이면, 그 축이 완전히 사라지므로 전체 부피도 0이 됩니다.

---

### 3.2 단위 행렬 $I$ — 변화 없음 ($\det = 1$)

$$
I = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}
$$

```python
# 단위 행렬 I 정의
I = np.array([[1, 0], [0, 1]])

# 행렬식 계산
det_I = np.linalg.det(I)
print(f"행렬식: {det_I}")  # 출력: 1.0

# 고유값 계산
lambdas, V = np.linalg.eig(I)
print(f"고유값들: {lambdas}")  # 출력: [1., 1.]

# 고유값의 곱
print(f"고유값의 곱: {np.prod(lambdas)}")  # 출력: 1.0

# 기저 벡터에 적용
B = np.array([[1, 0], [0, 1]])
IB = np.dot(I, B)
print(f"변환 후: \n{IB}")  # 출력: [[1, 0], [0, 1]] ← 변화 없음!
```

**기하학적 해석**:

- 모든 고유값이 1입니다: $1 \times 1 = 1$
- 각 축이 1배(그대로) 유지됩니다.
- 따라서 부피도 방향도 모두 **그대로 유지**됩니다.

**핵심 포인트**: 단위 행렬은 아무것도 변형하지 않는 "항등 변환"입니다.

---

### 3.3 변형 행렬 $J$ — 모양은 변하지만 크기는 유지 ($|\det| = 1$)

$$
J = \begin{bmatrix} -0.5 & 0 \\ 0 & 2 \end{bmatrix}
$$

```python
# 변형 행렬 J 정의
J = np.array([[-0.5, 0], [0, 2]])

# 행렬식 계산
det_J = np.linalg.det(J)
print(f"행렬식: {det_J}")  # 출력: -1.0
print(f"행렬식 절댓값: {np.abs(det_J)}")  # 출력: 1.0

# 고유값 계산
lambdas, V = np.linalg.eig(J)
print(f"고유값들: {lambdas}")  # 출력: [-0.5, 2.]

# 고유값의 곱
print(f"고유값의 곱: {np.prod(lambdas)}")  # 출력: -1.0

# 기저 벡터에 적용
B = np.array([[1, 0], [0, 1]])
JB = np.dot(J, B)
print(f"변환 후: \n{JB}")
# 출력: [[-0.5, 0], [0, 2]]
# x축 벡터: [1, 0] → [-0.5, 0] (반으로 줄고 뒤집힘)
# y축 벡터: [0, 1] → [0, 2] (두 배로 늘어남)
```

**기하학적 해석**:

- $x$축 방향: 0.5배로 줄어들고, 마이너스이므로 **반대 방향으로 뒤집힘**
- $y$축 방향: 2배로 늘어남
- 면적 변화: $0.5 \times 2 = 1$ → 면적은 그대로!
- 하지만 마이너스 부호 때문에 $\det = -1$ (공간이 뒤집힘)

**핵심 포인트**:

- 행렬식의 **절댓값이 1**이면 면적은 변하지 않습니다.
- 행렬식이 **음수**이면 거울 반사처럼 뒤집힙니다.
- 한쪽이 줄어도 다른 쪽이 같은 비율로 늘어나면 면적은 보존됩니다.

---

### 3.4 확장 행렬 $D$ — 공간의 확장 ($\det = 4$)

$$
D = \begin{bmatrix} 2 & 0 \\ 0 & 2 \end{bmatrix} = 2 \times I
$$

```python
# 확장 행렬 D 정의 (단위행렬 × 2)
I = np.array([[1, 0], [0, 1]])
D = I * 2  # 또는 np.array([[2, 0], [0, 2]])

print(f"행렬 D:\n{D}")
# 출력: [[2, 0], [0, 2]]

# 행렬식 계산
det_D = np.linalg.det(D)
print(f"행렬식: {det_D}")  # 출력: 4.0

# 고유값 계산
lambdas, V = np.linalg.eig(D)
print(f"고유값들: {lambdas}")  # 출력: [2., 2.]

# 고유값의 곱
print(f"고유값의 곱: {np.prod(lambdas)}")  # 출력: 4.0

# 기저 벡터에 적용
B = np.array([[1, 0], [0, 1]])
DB = np.dot(D, B)
print(f"변환 후: \n{DB}")
# 출력: [[2, 0], [0, 2]]
# x축 벡터: [1, 0] → [2, 0] (두 배)
# y축 벡터: [0, 1] → [0, 2] (두 배)
```

**기하학적 해석**:

- $x$축 방향: 2배로 늘어남
- $y$축 방향: 2배로 늘어남
- 면적 변화: $2 \times 2 = 4$ → **면적이 4배로 확장!**

**핵심 포인트**:

- 모든 고유값이 같은 값(2)이면, 모든 방향으로 균일하게 확대/축소됩니다.
- 이것을 **등방성 스케일링(Isotropic Scaling)**이라고 합니다.

## 4️⃣ 더 깊이 이해하기: 왜 이 관계가 성립하는가?

### 수학적 증명 (개념적)

행렬 $A$의 고유값 분해(Eigendecomposition)를 떠올려 봅시다:

$$
A = V \Lambda V^{-1}
$$

여기서:

- $V$: 고유벡터들을 열로 갖는 행렬
- $\Lambda$: 고유값들을 대각선에 갖는 대각행렬

행렬식의 성질을 적용하면:

$$
\det(A) = \det(V \Lambda V^{-1}) = \det(V) \cdot \det(\Lambda) \cdot \det(V^{-1})
$$

그리고 $\det(V^{-1}) = \frac{1}{\det(V)}$ 이므로:

$$
\det(A) = \det(V) \cdot \det(\Lambda) \cdot \frac{1}{\det(V)} = \det(\Lambda)
$$

대각행렬 $\Lambda$의 행렬식은 대각 원소들의 곱이므로:

$$
\det(\Lambda) = \lambda_1 \times \lambda_2 \times \dots \times \lambda_n = \prod_{i=1}^{n} \lambda_i
$$

따라서:

$$
\det(A) = \prod_{i=1}^{n} \lambda_i \quad \blacksquare
$$

## 🎯 요약

이 관계가 중요한 이유는 **머신러닝에서의 데이터 변환**을 이해하는 열쇠이기 때문입니다.

### 핵심 포인트 정리

| 개념                   | 의미                     | 역할                            |
| :--------------------- | :----------------------- | :------------------------------ |
| **고유값 ($\lambda$)** | 각 축별 스케일링 비율    | 개별 방향으로 얼마나 늘어나는지 |
| **행렬식 ($\det$)**    | 전체 부피 변화율         | 전체 공간이 얼마나 늘어나는지   |
| **관계**               | $\det = \prod \lambda_i$ | 개별을 곱하면 전체가 됨         |

### 직관적 이해

1. 데이터에 행렬을 곱한다는 것은 데이터를 늘리거나 줄이는 것입니다.
2. 그 늘어나고 줄어드는 비율의 총합(면적 변화)이 바로 **행렬식**입니다.
3. 각 축(Axis)별로 얼마나 늘어나고 줄어드는지를 나타내는 개별적인 수치가 **고유값**입니다.
4. 따라서 **개별 변화율(고유값)을 모두 곱하면 전체 변화율(행렬식)**이 되는 것은 너무나 당연하고 아름다운 결과입니다.

### 실용적 의미

- **$\det = 0$**: 정보 손실 발생 (역행렬 없음, 역변환 불가)
- **$|\det| < 1$**: 데이터 압축
- **$|\det| = 1$**: 정보량 보존 (회전, 반사 등)
- **$|\det| > 1$**: 데이터 확장

## 다음 단계: 고유값 분해 (Eigendecomposition)

행렬식과 고유값의 관계를 이해했다면, 이제 복잡한 행렬을 단순한 구성 요소로 쪼개는 **고유값 분해**를 배울 준비가 되었습니다.

- 행렬을 $A = V \Lambda V^{-1}$ 형태로 분해하여,
- 복잡한 행렬 연산을 **대각 행렬의 간단한 곱셈**으로 변환할 수 있습니다.
- 이는 **주성분 분석(PCA)**, **특이값 분해(SVD)** 등 머신러닝 핵심 알고리즘의 기초가 됩니다.
