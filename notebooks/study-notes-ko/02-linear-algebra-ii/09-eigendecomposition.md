# 9. 고유값 분해 (Eigendecomposition)

> **"복잡한 행렬을 단순한 구성 요소로 쪼개다"**

이번 장에서는 행렬의 **고유값 분해(Eigendecomposition)**에 대해 배웁니다. 고유값 분해는 행렬을 고유벡터와 고유값으로 분해하여 행렬의 본질적인 특성을 파악하는 강력한 도구입니다.

---

## 1️⃣ 고유값 분해란?

### 핵심 공식

어떤 정방행렬 $A$의 고유값 분해는 다음과 같이 정의됩니다:

$$
A = V \Lambda V^{-1}
$$

여기서:

- **$V$**: 모든 고유벡터를 **열(column)**로 갖는 행렬
- **$\Lambda$** (대문자 람다): 모든 고유값을 **대각선**에 갖는 대각행렬
- **$V^{-1}$**: $V$의 역행렬

### 각 요소의 의미

| 기호      | 이름            | 의미                                                    |
| :-------- | :-------------- | :------------------------------------------------------ |
| $V$       | 고유벡터 행렬   | 각 열이 하나의 고유벡터. 변환의 "방향"을 나타냄         |
| $\Lambda$ | 고유값 대각행렬 | 대각선에 고유값 배치. 각 방향별 "스케일(배율)"을 나타냄 |
| $V^{-1}$  | 고유벡터 역행렬 | 원래 좌표계로 되돌리는 역할                             |

### 관례: 고유값 정렬

보통 관례적으로 고유값을 **내림차순**으로 정렬합니다:

$$
\lambda_1 \geq \lambda_2 \geq \dots \geq \lambda_n
$$

이렇게 하면 **첫 번째 고유값과 고유벡터가 행렬 $A$의 가장 중요한 특성**을 나타내게 됩니다.

---

## 2️⃣ 왜 고유값 분해가 중요한가?

### 머신러닝에서의 활용

1. **행렬의 특성 파악**: 고유값과 고유벡터는 행렬의 본질적인 특성을 나타냅니다.

2. **특이 행렬 판별**: 만약 고유값 중 하나가 **0**이면, 그 행렬은 특이 행렬(Singular Matrix)입니다.

   - 역행렬이 존재하지 않음
   - 이전 영상 "행렬식과 고유값"에서 배운 개념!

3. **함수 최적화**: 특수한 조건 하에서:

   - 함수 $f(x)$의 **최대값** = 최대 고유값
   - 함수 $f(x)$의 **최소값** = 최소 고유값
   - (Goodfellow et al., 2016 Deep Learning Book 2.7장 참조)

4. **차원 축소**: PCA(주성분 분석)의 핵심 원리

---

## 3️⃣ NumPy로 고유값 분해 구현하기

### 예제: 2x2 행렬의 고유값 분해

```python
import numpy as np

# 행렬 A 정의 (정수 고유값을 갖도록 설정)
A = np.array([[4, 2],
              [-5, -3]])
print(f"원본 행렬 A:\n{A}")
# 출력:
# [[ 4,  2]
#  [-5, -3]]
```

### 1단계: 고유값과 고유벡터 구하기

```python
# np.linalg.eig로 고유값(lambdas)과 고유벡터(V) 계산
lambdas, V = np.linalg.eig(A)

print(f"고유값 (lambdas): {lambdas}")
# 출력: [ 2. -1.]  ← 깔끔한 정수 고유값!

print(f"고유벡터 행렬 (V):\n{V}")
# 출력:
# [[ 0.70710678 -0.37139068]
#  [-0.70710678  0.92847669]]
# 각 열이 하나의 고유벡터
```

### 2단계: V의 역행렬 구하기

```python
# V의 역행렬 계산
Vinv = np.linalg.inv(V)
print(f"V의 역행렬 (V⁻¹):\n{Vinv}")
# 출력:
# [[2.3570226  0.94280904]
#  [1.79505494 1.79505494]]
```

### 3단계: 대각행렬 Λ 만들기

```python
# 고유값으로 대각행렬 생성
Lambda = np.diag(lambdas)
print(f"고유값 대각행렬 (Λ):\n{Lambda}")
# 출력:
# [[ 2.  0.]
#  [ 0. -1.]]
# 주대각선에 고유값, 나머지는 0
```

### 4단계: 분해 공식 검증 ($A = V \Lambda V^{-1}$)

```python
# V × Λ × V⁻¹ 계산
A_reconstructed = np.dot(V, np.dot(Lambda, Vinv))
print(f"V × Λ × V⁻¹ = \n{A_reconstructed}")
# 출력:
# [[ 4.  2.]
#  [-5. -3.]]

# ✅ 원본 행렬 A와 완벽하게 일치!
```

### 전체 코드 요약

```python
import numpy as np

# 1. 행렬 정의
A = np.array([[4, 2], [-5, -3]])

# 2. 고유값 분해
lambdas, V = np.linalg.eig(A)
Vinv = np.linalg.inv(V)
Lambda = np.diag(lambdas)

# 3. 검증: A = V Λ V⁻¹
A_check = np.dot(V, np.dot(Lambda, Vinv))

print("원본 A:")
print(A)
print("\nV × Λ × V⁻¹:")
print(A_check)
print("\n동일한가?:", np.allclose(A, A_check))  # True
```

## 4️⃣ 실제 대칭행렬의 특수 케이스

### 머신러닝에서 대칭행렬이 흔한 이유

머신러닝에서는 주로 **실제 대칭행렬(Real Symmetric Matrix)**을 다룹니다:

- 공분산 행렬
- 그램 행렬
- 커널 행렬

대칭행렬은 주대각선을 기준으로 뒤집으면 원래 행렬과 동일합니다: $A = A^T$

### 대칭행렬의 고유값 분해 (더 간단한 공식!)

실제 대칭행렬 $A$의 경우, 고유값 분해가 **더 간단해집니다**:

$$
A = Q \Lambda Q^T
$$

여기서:

- **$Q$**: 직교행렬(Orthogonal Matrix)로 구성된 고유벡터 행렬
- **$\Lambda$**: 고유값 대각행렬
- **$Q^T$**: $Q$의 **전치행렬** (역행렬 아님!)

### 왜 더 편리한가?

| 일반 행렬                   | 대칭 행렬              |
| :-------------------------- | :--------------------- |
| $A = V \Lambda V^{-1}$      | $A = Q \Lambda Q^T$    |
| 역행렬 계산 필요 ($V^{-1}$) | 전치만 하면 됨 ($Q^T$) |
| 계산량 많음                 | 계산량 적음            |
| 복소수 포함 가능            | 항상 실수              |

**직교행렬의 특성**: $Q^{-1} = Q^T$ (역행렬 = 전치행렬)

### NumPy로 대칭행렬 고유값 분해

```python
import numpy as np

# 대칭행렬 S 정의 (주대각선 기준 대칭)
S = np.array([[3, 1],
              [1, 2]])
print(f"대칭행렬 S:\n{S}")
# 확인: S와 S의 전치가 같음
print(f"S == S.T: {np.allclose(S, S.T)}")  # True

# 고유값과 고유벡터 계산
lambdas, Q = np.linalg.eig(S)
print(f"\n고유값: {lambdas}")
# 출력: [3.61803399 1.38196601]

print(f"\n고유벡터 행렬 Q:\n{Q}")
```

### 대각행렬 생성 및 검증

```python
# 대각행렬 Λ 생성
Lambda = np.diag(lambdas)
print(f"고유값 대각행렬 Λ:\n{Lambda}")

# 검증: S = Q Λ Qᵀ (역행렬 대신 전치!)
S_reconstructed = np.dot(Q, np.dot(Lambda, Q.T))
print(f"\nQ × Λ × Qᵀ:\n{S_reconstructed}")
# 출력: 원본 S와 동일!

print(f"\n동일한가?: {np.allclose(S, S_reconstructed)}")  # True
```

### Q가 직교행렬임을 증명

직교행렬의 정의: $Q Q^T = Q^T Q = I$ (단위행렬)

```python
# Q가 직교행렬인지 확인
QQt = np.dot(Q, Q.T)
QtQ = np.dot(Q.T, Q)

print(f"Q × Qᵀ:\n{QQt}")
# 출력 (단위행렬에 매우 가까움):
# [[1.00000000e+00 2.23...e-17]
#  [2.23...e-17 1.00000000e+00]]

print(f"\n단위행렬과 같은가?: {np.allclose(QQt, np.eye(2))}")  # True
```

**참고**: `2.23e-17` 같은 아주 작은 값은 컴퓨터의 부동소수점 오차일 뿐, 실제로는 0입니다.

## 5️⃣ 고유값 분해의 한계

### 모든 행렬에 적용 가능한가?

**아닙니다!** 고유값 분해에는 제약이 있습니다:

1. **정방행렬만 가능**: $n \times n$ 행렬만 분해 가능
2. **복소수 포함 가능**: 실수 행렬이라도 고유값/고유벡터가 복소수일 수 있음
3. **분해 불가능한 경우 있음**: 일부 결함 행렬(Defective Matrix)은 분해 불가

### 머신러닝에서의 해결책

다행히 머신러닝에서 주로 다루는 **실제 대칭행렬**은:

- 항상 분해 가능
- 항상 실수 고유값/고유벡터
- 계산이 효율적

더 일반적인 경우에는 **특이값 분해(SVD)**를 사용합니다 (다음 장에서 학습).

## 🎯 요약

### 핵심 공식

| 행렬 유형         | 고유값 분해 공식       | 특징                    |
| :---------------- | :--------------------- | :---------------------- |
| **일반 정방행렬** | $A = V \Lambda V^{-1}$ | 역행렬 계산 필요        |
| **실제 대칭행렬** | $A = Q \Lambda Q^T$    | 전치만 필요 (더 효율적) |

### 핵심 개념

1. **$V$ (또는 $Q$)**: 고유벡터들의 열 → 변환의 "방향"
2. **$\Lambda$**: 고유값 대각행렬 → 각 방향별 "스케일"
3. **분해의 의미**: 복잡한 행렬 연산 → 간단한 대각행렬 연산으로 변환

### 머신러닝 활용

- **PCA (주성분 분석)**: 고유벡터 = 주성분 방향, 고유값 = 분산 설명량
- **함수 최적화**: 최대/최소 고유값 = 함수의 최대/최소값
- **특이 행렬 판별**: 고유값 0 → 역행렬 없음
