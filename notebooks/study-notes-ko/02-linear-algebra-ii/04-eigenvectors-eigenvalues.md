## 1. 아주 쉬운 비유: "바람개비와 화살표"

상상해 보세요. 여러분 책상 위에 수많은 **화살표(벡터)**가 놓여 있습니다. 이 화살표들은 각자 다른 방향을 가리키고 있습니다.

이제 여러분이 책상 위의 공간을 **누르고, 당기고, 비틀어** 봅니다. 이것이 바로 **행렬(Matrix)**이 하는 일입니다. 행렬은 공간을 변형시킵니다.

공간이 변형되면 화살표들도 같이 움직이겠죠?

- 대부분의 화살표는 **방향이 바뀝니다.** (오른쪽을 보던 게 위를 보게 되거나 합니다.)
- 그런데! **정말 신기하게도 방향이 전혀 변하지 않는 화살표**가 딱 몇 개 있습니다.

👉 **고유벡터(Eigenvector)**: 공간이 휘몰아쳐도 **자기 방향을 꿋꿋이 지키는 고집쟁이 화살표**.  
👉 **고유값(Eigenvalue)**: 그 고유벡터가 **얼마나 길어졌거나 줄어들었는지**를 나타내는 숫자. (방향은 그대로지만 크기만 변합니다.)

---

## 2. 모나리자 그림으로 이해하기

고유벡터를 이해하는 가장 유명한 예시인 '모나리자' 그림을 다시 봅시다.

### 상황 1: 그림을 좌우로 뒤집기 (거울처럼)

모나리자 그림의 정중앙을 세로로 가르는 **빨간 선(Y축)**과 가로로 가르는 **파란 선(X축)**이 있다고 칩시다.

1.  그림을 좌우로 확 뒤집습니다.
2.  **빨간 선(세로)**: 뒤집어도 그대로 제자리에 서 있죠? 움직이지 않았습니다. (방향 유지 성공!)
    - 🎉 **축하합니다! 빨간 선은 '고유벡터'입니다.**
3.  **파란 선(가로)**: 오른쪽을 가리키던 화살표가 이제 왼쪽을 가리킵니다. 방향이 180도 바뀌었지만, 여전히 **'가로줄'이라는 길 위**에 있습니다. 길을 벗어나지 않았습니다.
    - 🎉 **축하합니다! 파란 선도 '고유벡터'입니다.** (단, 방향이 반대라 고유값은 -1이 됩니다.)
4.  **대각선 화살표**: 만약 대각선 방향의 화살표가 있었다면? 뒤집으면서 방향이 완전히 엉뚱한 곳으로 바뀝니다.
    - ❌ **탈락! 고유벡터가 아닙니다.**

### 상황 2: 그림을 옆으로 밀기 (이탤릭체처럼)

이번엔 그림의 윗변을 잡고 오른쪽으로 쓱 밉니다.

1.  **파란 선(가로)**: 밑변은 고정되어 있으니 가로선은 그대로입니다.
    - 🎉 **고유벡터입니다.**
2.  **빨간 선(세로)**: 그림이 옆으로 기울어지면서 빨간 선도 오른쪽으로 비스듬히 누워버립니다. 원래 서 있던 자리를 이탈했습니다.
    - ❌ **고유벡터가 아닙니다.**

> **정리**: "행렬(변환)이라는 폭풍이 지나가도, 원래 서 있던 직선(Line) 위에서 벗어나지 않는 벡터"가 바로 고유벡터입니다.

---

## 3. 수식, 이제는 무섭지 않다 ($Av = \lambda v$)

$$
Av = \lambda v
$$

- **$A$ (행렬)**: 변환을 일으키는 힘 (예: 밀기, 뒤집기, 회전)
- **$v$ (고유벡터)**: 방향을 지키는 벡터
- **$\lambda$ (고유값/람다)**: 길이 변화율

**해석**:

1.  **좌변 ($Av$)**: 벡터 $v$에 행렬 $A$의 힘을 가했습니다. (복잡한 변환)
2.  **우변 ($\lambda v$)**: 그랬더니 결과가 그냥 원래 $v$의 길이를 $\lambda$배 늘린 거랑 똑같습니다. (단순한 크기 조절)

👉 **"행렬 곱셈이라는 복잡한 일을, 단순한 숫자 곱셈으로 퉁칠 수 있게 해주는 고마운 녀석들"**입니다.

## 4. 파이썬으로 직접 찾아보자

"손으로 풀지 마세요. 컴퓨터에게 시키세요."

### 4.1 NumPy (가장 기본)

```python
import numpy as np

# 1. 행렬 A를 만듭니다. (변환 장치)
A = np.array([[-1, 4],
              [ 2, -2]])

# 2. 마법의 주문 'eig'를 쇱니다.
# 컴퓨터가 알아서 고유값(lambdas)과 고유벡터(V)를 찾아줍니다.
lambdas, V = np.linalg.eig(A)

print("고유값들:", lambdas)
# 예: [1.37, -4.37] -> 하나는 1.3배 늘어났고, 하나는 뒤집히면서 4.3배 늘어났다는 뜻
print("고유벡터들:\n", V)
```

### 4.2 PyTorch (딥러닝용)

딥러닝을 위해 토치(Torch)도 써봅시다. 방식은 거의 똑같습니다.

```python
import torch

# 1. 행렬 만들기 (주의: 소수점을 찍어서 실수(float)로 만들어야 합니다!)
A_torch = torch.tensor([[-1., 4.],
                        [ 2., -2.]])

# 2. 고유값과 고유벡터 찾기
# torch.linalg.eig를 씁니다. (복소수라는 어려운 숫자가 나올 수 있어 실수로 바꿔줍니다)
result = torch.linalg.eig(A_torch)
lambdas_torch = result[0].float() # 고유값
vectors_torch = result[1].float() # 고유벡터

print("고유값:", lambdas_torch)
print("고유벡터:\n", vectors_torch)
```

## 5. 눈으로 확인하기 (시각화)

정말 방향이 안 변했는지 눈으로 봐야 믿겠죠? 그래프를 그려주는 코드입니다.

```python
import matplotlib.pyplot as plt

def plot_vectors(vectors, colors):
    plt.figure()
    plt.axvline(x=0, color='lightgray')
    plt.axhline(y=0, color='lightgray')
    for i in range(len(vectors)):
        # 화살표 그리기 (시작점 0,0)
        plt.quiver(0, 0, vectors[i][0], vectors[i][1], color=colors[i], angles='xy', scale_units='xy', scale=1)

# 실제 실행 예시
# v: 원래 고유벡터 (하늘색)
# Av: 변환된 고유벡터 (파란색)
v = vectors_torch[:, 0]  # 첫 번째 고유벡터
Av = torch.matmul(A_torch, v) # 변환 적용!

# 두 화살표 그리기
# 1. v.numpy(): PyTorch 텐서를 시각화 함수가 이해할 수 있는 NumPy 배열로 변환합니다.
# 2. ['lightblue', 'blue']: 변환 전(v)은 연한 파랑, 변환 후(Av)는 진한 파랑으로 색칠합니다.
plot_vectors([v.numpy(), Av.numpy()], ['lightblue', 'blue'])

# 3. 그래프의 X축, Y축 범위를 -2에서 2까지로 설정합니다.
# 이 범위 안에 화살표가 잘 들어오도록 조절하는 것입니다.
plt.xlim(-2, 2)
plt.ylim(-2, 2)
plt.show()
```

**결과를 보면**:
하늘색 화살표(원래) 위에 파란색 화살표(변환 후)가 **정확히 겹쳐서** 길이만 길어진 것을 볼 수 있습니다. 방향이 안 바뀌었다는 증거입니다!

## 요약

1.  **행렬**은 공간을 뒤흔듭니다.
2.  그 와중에 **방향을 잃지 않는 화살표**가 **고유벡터**입니다.
3.  화살표가 **얼마나 늘어났는지** 알려주는 숫자가 **고유값**입니다.
4.  이 친구들이 있으면 복잡한 계산이 아주 쉬워집니다.
