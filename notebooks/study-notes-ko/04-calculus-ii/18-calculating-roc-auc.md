# 18. ROC AUC 계산하기 (Calculating ROC AUC)

> **"적분을 향한 여정: 곡선 아래 면적 구하기"**

이제 실제로 ROC 곡선을 만들고 그 아래 면적(AUC)을 계산해 봅시다.
(복잡한 수식 대신 간단한 예제 데이터로 시작합니다)

---

## 1️⃣ 예제 데이터 (Toy Data Set)

핫도그 분류 문제라고 가정합니다.

- **실제($y$)**: [0, 0, 1, 1] (0: 아님, 1: 핫도그)
- **예측($\hat{y}$)**: [0.3, 0.6, 0.5, 0.9] (확신 정도)

---

## 2️⃣ Step 1: 다양한 임계값(Threshold)으로 자르기

예측값들($0.3, 0.5, 0.6$)을 각각 임계값으로 설정하고 혼동 행렬을 계산합니다.

### Case A: 임계값 = 0.3

($0.3$ 이하는 0, 초과는 1로 예측)

- **예측 결과**: [0, 1, 1, 1]
- **비교**:
  - TN: 1개 (첫 번째 0)
  - FP: 1개 (두 번째 0을 1로 예측)
  - TP: 2개 (두 1을 모두 1로 예측)
  - FN: 0개

### Case B: 임계값 = 0.5

($0.5$ 이하는 0, 초과는 1)

- **예측 결과**: [0, 1, 0, 1]
- **비교**:
  - TN: 1개
  - FP: 1개
  - TP: 1개
  - FN: 1개 (세 번째 1을 0으로 예측)

### Case C: 임계값 = 0.6

($0.6$ 이하는 0, 초과는 1)

- **예측 결과**: [0, 0, 0, 1]
- **비교**:
  - TN: 2개 (두 0을 모두 0으로 잘 예측)
  - FP: 0개
  - TP: 1개
  - FN: 1개

---

## 3️⃣ Step 2: TPR과 FPR 계산

각 임계값마다 두 가지 비율을 구합니다.

1. **TPR (True Positive Rate) = Recall (재현율)**

   - 실제 핫도그 중 몇 개나 맞췄나?
   - $$ TPR = \frac{TP}{TP + FN} $$

2. **FPR (False Positive Rate)**
   - 핫도그가 아닌 것 중 몇 개를 핫도그라고 틀렸나?
   - $$ FPR = \frac{FP}{FP + TN} $$

| 임계값  | TPR         | FPR         |
| :------ | :---------- | :---------- |
| **0.3** | $2/2 = 1.0$ | $1/2 = 0.5$ |
| **0.5** | $1/2 = 0.5$ | $1/2 = 0.5$ |
| **0.6** | $1/2 = 0.5$ | $0/2 = 0.0$ |

---

## 4️⃣ Step 3: ROC 곡선 그리기

- **X축**: FPR
- **Y축**: TPR
- 점들을 찍고 연결합니다. [(0.5, 1.0), (0.5, 0.5), (0.0, 0.5)]
- 양 끝점 (0,0)과 (1,1)도 추가합니다.

이렇게 그려진 곡선이 바로 **ROC Curve**입니다.

---

## 5️⃣ Step 4: AUC (Area Under Curve) 계산

이 곡선 아래의 면적을 구합니다. 이것이 **AUC**입니다.

- **범위**: 0.0 ~ 1.0
- **0.5**: 완전 랜덤 (동전 던지기 수준)
- **1.0**: 완벽한 분류기 (Perfect Classifier)
- 우리 예제에서는 약 **0.75**가 나옵니다.

> **이 면적을 구하는 수학적 방법이 바로 '적분(Integral)'입니다.**
> 다음 장부터는 이 면적을 구하기 위해 적분을 본격적으로 사용해보겠습니다.
