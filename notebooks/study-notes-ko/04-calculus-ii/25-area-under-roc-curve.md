# 25. ROC 곡선 아래 면적 구하기 (Calculating Area Under ROC Curve)

> **"적분의 최종 응용: 머신러닝 성능 평가"**

우리가 수동으로 그렸던 ROC 곡선의 좌표를 이용해, 이번에는 **Python**으로 곡선 아래 면적(AUC)을 계산해 봅니다.
사이킷런(scikit-learn) 라이브러리를 사용하면 아주 간단하게 구할 수 있습니다.

---

## 1️⃣ 데이터 준비 (좌표)

이전 강의에서 구한 (FPR, TPR) 좌표들입니다.

| 점 (Point) | FPR ($x$) | TPR ($y$) | 설명            |
| :--------- | :-------- | :-------- | :-------------- |
| **Start**  | 0         | 0         | 시작점          |
| **0.6**    | 0         | 0.5       | 임계값 0.6일 때 |
| **0.5**    | 0.5       | 0.5       | 임계값 0.5일 때 |
| **0.3**    | 0.5       | 1         | 임계값 0.3일 때 |
| **End**    | 1         | 1         | 끝점            |

---

## 2️⃣ 파이썬 코드 구현

`sklearn.metrics.auc` 함수를 사용합니다. 이 함수는 **사다리꼴 법칙(Trapezoidal Rule)**을 사용해 적분 값을 근사적으로 계산합니다.

```python
from sklearn.metrics import auc

# 1. 좌표 정의
xs = [0, 0, 0.5, 0.5, 1] # FPR
ys = [0, 0.5, 0.5, 1, 1] # TPR

# 2. AUC 계산
result = auc(xs, ys)

print(result)
```

### 실행 결과

```
0.75
```

- 우리가 눈으로 보고 짐작했던 면적($3/4$)과 정확히 일치합니다.

---

## 🎯 의미

- **AUC = 0.75**: 이 모델은 무작위 추측(0.5)보다는 낫지만, 완벽(1.0)하지는 않은, 준수한 성능을 보여줍니다.
- **적분의 힘**: 함수식이 없어도, 데이터 포인트(좌표)만 있으면 **수치 적분**을 통해 면적을 구할 수 있습니다. 이것이 머신러닝에서 적분이 활용되는 대표적인 예입니다.
