# 23. 파이썬으로 정적분 계산하기 (Numerical Integration in Python)

> **"손으로 풀기 힘들 땐, 컴퓨터에게 맡기자"**

앞서 손으로 계산했던 정적분($\int_{1}^{2} \frac{x}{2} dx = 0.75$)을 파이썬의 `scipy` 라이브러리를 이용해 수치적으로(Numerically) 계산해 보겠습니다.
이 방법은 공식(Symbolic)을 몰라도 계산할 수 있어 매우 강력합니다.

---

## 1️⃣ 코드 구현

`scipy.integrate.quad` 함수를 사용합니다. ('Quadrature'는 적분의 옛말입니다)

```python
from scipy.integrate import quad

# 1. 적분할 함수 정의 (y = x/2)
def g(x):
    return x / 2

# 2. 정적분 수행 (함수, 시작점, 끝점)
# quad(func, a, b) -> (integral, error)
result = quad(g, 1, 2)

print(result)
```

---

## 2️⃣ 결과 해석

위 코드를 실행하면 다음과 같은 튜플(Tuple)이 반환됩니다.

```
(0.75, 8.326672684688674e-15)
```

1. **첫 번째 값 (0.75)**: 적분 결과입니다. 우리가 손으로 계산한 값과 정확히 일치합니다.
2. **두 번째 값 ($8.3 \times 10^{-15}$)**: 오차 추정치(Absolute Error Estimate)입니다.
   - 수치 적분은 근사 계산이므로 오차가 발생할 수 있습니다.
   - 하지만 이 값은 $0.000000000000008...$로 거의 0에 가깝습니다. 즉, **결과를 매우 신뢰**할 수 있습니다.

---

## 🎯 활용

복잡한 함수라도 `def`로 정의만 할 수 있다면, `quad` 함수에 넣어 구간($a, b$)만 지정하면 면적을 즉시 구할 수 있습니다.
