# 05. 무한소의 미적분 (Calculus of Infinitesimals)

> **"무한히 확대하면 곡선도 직선이 된다"**

이번 장에서는 **곡선의 기울기(Slope)**를 구하기 위해 **무한소(Infinitesimals)** 개념을 미분에 어떻게 적용하는지 알아봅니다. 파이썬 코드를 통해 곡선을 직접 확대(Zoom-in)해보면서 시각적으로 확인해 봅시다.

---

## 1️⃣ 핵심 아이디어

곡선 위의 한 점에서의 기울기, 즉 **접선(Tangent Line)**을 구하는 것은 어렵습니다. 곡선은 계속 휘어지기 때문입니다.

하지만, 곡선의 한 부분을 **무한히 확대**해서 본다면?

- 곡선은 점점 평평해져서 결국 **직선**처럼 보입니다.
- 직선의 기울기를 구하는 것은 쉽습니다!

이것이 바로 미분에서 곡선의 기울기(순간 변화율)를 구하는 원리입니다.

$$
\text{곡선을 무한히 확대} \approx \text{직선} \rightarrow \text{기울기 계산 가능}
$$

---

## 2️⃣ 파이썬 실습: 곡선 확대하기

함수 $y = x^2 + 2x + 2$를 예로 들어봅시다.

### 1단계: 전체 곡선 그리기

```python
import numpy as np
import matplotlib.pyplot as plt

# x값 범위: -10에서 10까지 1000개의 점 생성
x = np.linspace(-10, 10, 1000)

# 함수 정의: y = x^2 + 2x + 2
y = x**2 + 2*x + 2

# 그래프 그리기
fig, ax = plt.subplots()
ax.plot(x, y)
plt.title("전체 곡선 (-10 ~ 10)")
plt.show()
```

이 그래프는 매끄러운 U자 형태(Parabola)이며, 어디에도 직선은 보이지 않습니다.

### 2단계: 최저점 근처로 확대 (-2 ~ 0)

곡선의 기울기가 0이 되는 지점(최저점)을 찾기 위해 확대해 봅시다.

```python
fig, ax = plt.subplots()
ax.set_xlim([-2, 0])  # x 범위 축소
ax.set_ylim([0, 2])   # y 범위 축소
ax.plot(x, y)
plt.title("확대 1단계 (-2 ~ 0)")
plt.show()
```

여전히 곡선처럼 보입니다.

### 3단계: 더 가까이 확대 (-1.5 ~ -0.5)

```python
fig, ax = plt.subplots()
ax.set_xlim([-1.5, -0.5])
ax.set_ylim([0.5, 1.5])
ax.plot(x, y)
plt.title("확대 2단계 (-1.5 ~ -0.5)")
plt.show()
```

곡선이 조금 펴진 것처럼 보이지만, 아직 둥근 부분이 남아있습니다.

### 4단계: 무한히 가깝게 확대 (-1.01 ~ -0.99)

```python
fig, ax = plt.subplots()
ax.set_xlim([-1.01, -0.99])
ax.set_ylim([0.99, 1.01])
ax.plot(x, y)
plt.title("확대 3단계 (-1.01 ~ -0.99)")
plt.show()
```

**결과**: 이제 곡선은 **완벽한 직선(수평선)**처럼 보입니다!

- 이 지점($x \approx -1$)에서의 기울기는 **0**입니다. (수평선이므로)
- 즉, $x = -1$에서 함수는 최솟값을 가집니다.

## 🎯 결론

파이썬 실습을 통해 우리는 다음을 확인했습니다:

1. 멀리서 보면 휘어진 곡선이지만, **아주 가까이서(무한소의 영역에서) 보면 직선**과 같습니다.
2. 이 직선의 기울기가 바로 해당 지점에서의 **미분값(Derivative)**입니다.
3. 이 원리를 이용해 복잡한 곡선의 어느 지점에서든 기울기를 구할 수 있습니다.
