## 4\. 핵심 개념 상세 분석

### 4.1 극한(Limit) 미분의 초석

극한은 미적분학의 문을 여는 열쇠다. 어떤 함수에서 입력값이 특정 값에 한없이 가까워질 때, 출력값이 도달하는 목표 지점을 의미한다.

  * **실진법(Method of Exhaustion):** 고대 그리스의 아르키메데스가 원의 넓이를 구하기 위해 다각형의 변을 무한히 늘려가던 방식에서 유래했다. 이는 적분의 기초 아이디어이기도 하다.
  * **무한소(Infinitesimal):** 0은 아니지만 0에 한없이 가까운 상태. 미분은 이 '찰나의 순간'에 일어나는 변화를 포착한다.
  * **연속성(Continuity):** 머신러닝의 손실 함수(Loss Function)는 대부분 미분 가능해야 하므로, 그래프가 끊어지지 않고 부드럽게 이어지는 연속성은 매우 중요한 성질이다.

### 4.2 도함수(Derivative) 학습의 방향성

도함수는 특정 지점에서의 '순간 변화율'이다. 기하학적으로는 곡선 위의 한 점에서의 **접선의 기울기**를 의미한다.

  * **변화율의 의미:** 입력($x$)이 아주 미세하게 변할 때, 출력($y$)이 얼마나 민감하게 반응하는지를 나타낸다.
  * **기울기가 양수(+)일 때:** 파라미터를 늘리면 오차도 커진다. (줄여야 한다)
  * **기울기가 음수(-)일 때:** 파라미터를 늘리면 오차가 줄어든다. (늘려야 한다)
  * **기울기가 0일 때:** 변화가 없는 지점. 최적점(Global Minimum)이거나 안장점(Saddle Point)일 수 있다.

#### 주요 미분 법칙

머신러닝 모델(특히 신경망)은 수많은 함수의 합성으로 이루어져 있다. 이를 미분하기 위해 다음 법칙들이 필수적으로 사용된다.

1.  **거듭제곱 법칙 (Power Rule):** 다항식 미분의 기초.
2.  **곱의 법칙 (Product Rule):** 두 함수의 곱을 미분하는 법.
3.  **연쇄 법칙 (Chain Rule):** **(가장 중요)** 합성함수의 미분법. 딥러닝의 **역전파(Backpropagation)** 알고리즘은 본질적으로 연쇄 법칙을 거꾸로 적용하는 과정이다.

### 4.3 자동 미분(Automatic Differentiation) 현대 AI의 무기

과거에는 종이와 펜으로 미분을 풀었지만, 수억 개의 파라미터를 가진 거대 언어 모델(LLM)을 손으로 미분하는 것은 불가능하다. 여기서 '자동 미분'이 등장한다.

  * **수치 미분 (Numerical Differentiation):** $h$를 아주 작은 수로 설정하여 근사치를 구하는 방식. 구현은 쉽지만 오차가 발생하고 계산 비용이 높다.
  * **기호 미분 (Symbolic Differentiation):** 사람이 푸는 것처럼 수식 자체를 변형하는 방식. 식이 매우 복잡해지는 '수식 팽창(Expression Swell)' 문제가 있다.
  * **자동 미분 (AutoDiff):** 컴퓨터가 연산 그래프(Computational Graph)를 그리고, 연쇄 법칙을 적용하여 정확한 미분값을 효율적으로 계산하는 방식. TensorFlow와 PyTorch의 핵심 기술이다.

## 5\. 실전 사용법 파이썬으로 구현하는 미적분

이론을 배웠다면 코드로 구현할 수 있어야 한다. 본 핸드북에서는 Python 생태계의 주요 라이브러리를 활용한 방법을 소개한다.

### 5.1 NumPy를 활용한 수치 미분

NumPy는 자동 미분을 기본적으로 지원하지 않지만, 미분의 개념을 이해하기 위해 수치 미분을 직접 구현해 볼 수 있다.

```python
import numpy as np

def numerical_derivative(f, x):
    h = 1e-4 # 아주 작은 값 (델타 x)
    return (f(x + h) - f(x)) / h
```

### 5.2 PyTorch를 활용한 자동 미분 (Autograd)

PyTorch는 `autograd` 모듈을 통해 텐서의 연산 기록을 추적하고, `.backward()` 메서드 하나로 모든 기울기(Gradient)를 자동으로 계산한다.

```python
import torch

x = torch.tensor(3.0, requires_grad=True) # 기울기 추적 활성화
y = x ** 2 + 2 * x + 1

y.backward() # 역전파 수행
print(x.grad) # dy/dx 값 출력 (2x + 2 = 8.0)
```

### 5.3 TensorFlow를 활용한 자동 미분 (GradientTape)

TensorFlow는 `GradientTape` 컨텍스트 내에서 실행된 연산을 기록하고, 이를 바탕으로 미분을 수행한다.

```python
import tensorflow as tf

x = tf.Variable(3.0)

with tf.GradientTape() as tape:
    y = x ** 2 + 2 * x + 1

dy_dx = tape.gradient(y, x)
print(dy_dx.numpy()) # 8.0
```

## 6\. 심화 분석 머신러닝에서의 응용

미적분학 1의 내용은 단순히 계산법을 익히는 것을 넘어 다음과 같은 핵심 ML 개념으로 확장된다.

### 6.1 경사 하강법 (Gradient Descent)

산 정상에서 가장 빠르게 내려가는 방법은 경사가 가장 가파른 방향으로 발을 내딛는 것이다.

  * **작동 원리:** 현재 위치에서 손실 함수(Loss Function)의 기울기(Gradient)를 구하고, 그 반대 방향으로 학습률(Learning Rate)만큼 이동한다.
  * **확률적 경사 하강법 (SGD):** 전체 데이터 대신 일부 데이터(Mini-batch)만 사용하여 기울기를 계산해 속도를 높이고 지역 최적해(Local Minima) 탈출 가능성을 높인다.

### 6.2 역전파 (Backpropagation)

심층 신경망(Deep Neural Network)의 출력 오차를 입력층 방향으로 전파하며 각 가중치의 기여도를 계산하는 알고리즘이다.

  * **미적분과의 관계:** 각 층의 활성화 함수와 가중치 연산에 대해 \*\*연쇄 법칙(Chain Rule)\*\*을 반복적으로 적용하는 과정이다. 미적분학 1에서 배우는 합성함수 미분이 그 토대가 된다.

### 6.3 최적화 (Optimization) 과목으로의 연결

본 시리즈의 마지막 과목인 '최적화'는 미적분학 1, 2와 선형대수학을 모두 통합한다.

  * 1차 도함수(기울기)뿐만 아니라, 2차 도함수(곡률, Hessian Matrix)를 활용하여 학습 속도를 조절하는 Newton's Method 등으로 개념이 확장된다.

# 머신러닝을 위한 미적분학 가이드 자동차 여행으로 이해하는 미분과 변화율

## 1. 서론 변화를 이해하는 언어 미적분학

우리가 살고 있는 세상은 멈춰 있지 않다. 행성의 궤도, 주식 시장의 변동, 그리고 달리는 자동차까지 모든 것은 끊임없이 변화한다. 미적분학(Calculus)은 이러한 **'지속적인 변화(Continuous Change)'**를 수학적으로 연구하는 학문이다.

많은 사람이 미적분을 복잡한 수식의 나열로 기억하지만, 본질적으로 미적분은 움직임을 이해하고 예측하기 위한 도구다. 머신러닝 분야에서 미적분은 데이터의 패턴을 학습하고 모델의 오차를 줄여나가는 '최적화' 과정의 핵심 엔진 역할을 한다.

이 핸드북은 존 크론(Dr. Jon Krohn) 박사의 강의를 바탕으로, 자동차 여행이라는 직관적인 비유를 통해 미적분학의 첫 번째 기둥인 **미분(Differentiation)**과 **도함수(Derivative)**의 개념을 완벽하게 분해한다. 우리는 거리, 속도, 가속도의 관계를 통해 정적인 그래프에서 역동적인 변화율을 읽어내는 방법을 배울 것이다.

## 2. 미적분학의 두 가지 기둥

본격적인 내용에 앞서 미적분학의 큰 그림을 이해할 필요가 있다. 미적분학은 크게 두 가지 상호 보완적인 분야로 나뉜다.

| 구분 | 초점 | 주요 내용 | 비유 |
| :--- | :--- | :--- | :--- |
| **미분 (Differential Calculus)** | **변화율** | 어떤 현상이 얼마나 빠르게 변하는가? (기울기, 도함수) | 케이크를 얇게 썰어 단면을 분석하는 것 |
| **적분 (Integral Calculus)** | **누적량** | 변화하는 양을 쌓으면 총 얼마나 되는가? (면적, 부피) | 얇은 케이크 조각들을 모아 전체 형태를 만드는 것 |

이번 핸드북에서는 **미분**에 집중한다. 미분은 어떤 함수의 순간적인 변화를 포착하여 새로운 함수(도함수)를 만들어내는 과정이다.

## 3. 첫 번째 단계 위치와 시간의 관계 (거리 그래프)

미분의 개념을 가장 직관적으로 이해하는 방법은 **'이동(Movement)'**을 관찰하는 것이다. $t$분 동안 $d$km를 이동하는 자동차 여행을 상상해 보자.

### 3.1 시나리오 설정
1.  **출발:** 집(거리 0)에서 출발하여 자동차를 가속한다.
2.  **정차:** 5분 지점에서 편의점에 들러 간식을 사기 위해 멈춘다.
3.  **재출발:** 다시 차에 타서 고속도로로 진입한다.
4.  **주행:** 고속도로에서 크루즈 컨트롤(Cruise Control)을 켜고 일정한 속도로 주행한다.



### 3.2 그래프 분석과 접선(Tangent Line)
이 여정을 **거리(y축) 대 시간(x축)** 그래프로 그리면 다음과 같은 특징을 발견할 수 있다.

* **곡선 구간 (가속):** 처음 출발할 때 그래프는 완만한 곡선으로 시작해 점점 가파라진다. 이는 시간이 지날수록 이동 거리가 급격히 늘어남을 의미한다.
* **수평 구간 (정지):** 가게에 머무는 동안 시간은 흐르지만 거리는 변하지 않는다. 그래프는 평평한 수평선이 된다.
* **직선 구간 (정속 주행):** 고속도로에서는 일정한 속도로 달리므로 그래프는 일직선으로 뻗어나간다.

여기서 핵심 개념인 **'접선(Tangent Line)'**이 등장한다. 곡선 위의 특정 한 점을 스치듯 지나가는 직선을 그리면, 그 직선의 기울기가 바로 그 순간의 변화율이다.
* 곡선이 가파를수록 접선의 기울기는 크다.
* 곡선이 평평하면 접선의 기울기는 0이다.

## 4. 두 번째 단계 속도의 발견 (1차 도함수)

우리가 앞서 관찰한 거리 그래프의 **기울기(Slope)**는 무엇을 의미할까?
수학적으로 기울기 $m$은 다음과 같이 정의된다.

$$m = \frac{\Delta y}{\Delta x} = \frac{\text{거리의 변화량}}{\text{시간의 변화량}}$$

거리의 변화를 시간의 변화로 나눈 값, 이것이 바로 **속도(Velocity)**다. 즉, 거리 그래프를 미분하면 속도 그래프를 얻을 수 있다. 이를 **도함수(Derivative)**를 구했다고 표현한다.

### 4.1 거리 그래프의 기울기를 속도 값으로 변환
이제 거리 그래프의 각 지점에서 기울기를 측정해 새로운 그래프(속도 대 시간)에 옮겨 그려보자.

1.  **가속 구간:**
    * 거리 그래프의 기울기가 점점 가파라진다 (예: 0.5 $\rightarrow$ 1 $\rightarrow$ 2).
    * **속도 그래프:** $y$값이 0에서 시작해 점점 높아지는 우상향 직선이 된다.
2.  **정지 구간:**
    * 거리 그래프가 수평이다 (기울기 = 0).
    * **속도 그래프:** $y$값이 0인 바닥에 붙은 선이 된다. (속도가 0임을 의미)
3.  **정속 주행 구간:**
    * 거리 그래프가 일정한 기울기의 직선이다 (예: 기울기 = 1).
    * **속도 그래프:** $y$값이 1인 위치에서 수평선이 된다. (속도가 변하지 않고 일정함)



이 과정을 통해 우리는 **"위치(거리)의 도함수는 속도이다"**라는 물리학의 기본 법칙을 시각적으로 확인했다.

## 5. 세 번째 단계 가속도의 이해 (2차 도함수)

미분의 마법은 여기서 끝나지 않는다. 속도 그래프 자체도 시간에 따라 변화한다. 속도가 변화하는 비율, 즉 속도 그래프의 기울기는 무엇일까?

$$m = \frac{\Delta v}{\Delta t} = \frac{\text{속도의 변화량}}{\text{시간의 변화량}} = \text{가속도(Acceleration)}$$

속도 그래프를 다시 한번 미분하면 **가속도** 그래프를 얻게 된다. 이것이 원래 거리 함수의 **2차 도함수(Second Derivative)**다.

### 5.1 속도 그래프의 기울기를 가속도 값으로 변환
1.  **가속 구간 (속도가 빨라짐):**
    * 속도 그래프가 우상향한다 (기울기가 양수).
    * **가속도 그래프:** 양(+)의 값을 가진다. 내가 엑셀을 밟고 있다는 뜻이다.
2.  **감속 구간 (가게 도착 전):**
    * 속도 그래프가 우하향한다 (기울기가 음수).
    * **가속도 그래프:** 음(-)의 값을 가진다. 브레이크를 밟고 있다는 뜻이다.
3.  **정속 주행 및 정지 구간:**
    * 이 부분이 가장 중요하다. 가게에 멈춰 있을 때(속도=0)와 고속도로를 달릴 때(속도=100km/h)는 상태가 다르다.
    * 하지만 **두 경우 모두 속도 그래프의 기울기는 0이다.** (수평선)
    * **가속도 그래프:** 두 구간 모두 가속도는 0이다. 속도가 변하지 않기 때문이다.



## 6. 심화 분석 머신러닝에서의 응용

자동차 비유는 이해하기 쉽지만, 이 개념이 머신러닝(ML)에서 어떻게 쓰이는지 아는 것이 중요하다. ML 모델 학습은 이 '자동차 운전'과 놀라울 정도로 닮아 있다.

### 6.1 손실 함수와 경사 하강법 (Gradient Descent)
머신러닝의 목표는 예측의 오차(Loss)를 최소화하는 것이다.
* **거리 그래프 $\approx$ 손실 함수(Loss Function):** 우리가 최소화하고 싶은 오차의 지형이다.
* **기울기(미분값) $\approx$ 학습의 방향:** 현재 위치에서 오차가 줄어드는 방향을 찾기 위해 미분을 사용한다.
* **경사 하강법:** 기울기가 가파른 곳에서는 성큼성큼 내려가고(학습률 조정), 평평한 곳(최적점)에 다다르면 멈추는 알고리즘이다.

### 6.2 고차 미분의 활용
* **1차 도함수 (속도):** 오차가 줄어드는 방향(기울기)을 알려준다.
* **2차 도함수 (가속도):** 곡선의 굴곡(Curvature)을 알려준다. 이는 오차 지형이 밥그릇처럼 오목한지, 산봉우리처럼 볼록한지를 파악하게 해 주어 학습 속도를 최적화하는 데 사용된다 (예: Hessian Matrix).

## 7. 핵심 요약 및 결론

이 핸드북을 통해 우리는 미분이란 단순히 공식을 외우는 것이 아니라, **변화의 흐름을 읽어내는 기술**임을 배웠다.

1.  **미분은 변화율이다:** 어떤 그래프의 특정 지점에서의 기울기는 그 순간의 변화 속도를 의미한다.
2.  **연쇄적 관계:** 거리를 미분하면 속도가 되고, 속도를 미분하면 가속도가 된다.
3.  **0의 의미:** 그래프가 수평이면 미분값(기울기)은 0이다. 이는 변화가 없는 상태(정지 혹은 정속)를 의미하며, 머신러닝에서는 최적점(Minimum)을 찾는 중요한 단서가 된다.

# 머신러닝의 완성을 위한 적분 기초 곡선 아래의 면적과 역연산의 미학

## 1\. 서론 미분의 대척점, 적분의 세계로

미적분학(Calculus)은 변화를 다루는 거대한 수학적 체계다. 우리가 앞서 살펴본 \*\*미분(Differentiation)\*\*이 대상을 잘게 쪼개어 순간의 변화율을 분석하는 현미경이었다면, \*\*적분(Integration)\*\*은 그 쪼개진 조각들을 다시 쌓아 올려 전체의 양을 파악하는 망원경과 같다.

존 크론 박사의 머신러닝 기초 강의 시리즈 중 이번 파트는 미적분학의 두 번째 기둥인 '적분'을 소개한다. 많은 학습자가 미분에서 기울기를 구하는 것에 익숙해져 있지만, 적분이 왜 필요한지, 그리고 그것이 미분과 어떤 관계인지 직관적으로 이해하는 데 어려움을 겪는다. 이 핸드북은 자동차 주행이라는 친숙한 비유를 통해 적분의 본질인 \*\*'곡선 아래의 영역(Area under the curve)'\*\*과 \*\*'누적(Accumulation)'\*\*의 개념을 명확히 정리한다. 이는 향후 미적분학 2에서 다룰 심화 내용의 초석이 될 것이다.

## 2\. 적분의 정의와 탄생 배경

### 2.1 변화를 쌓아 올리는 학문

고대부터 수학자들은 불규칙한 모양의 땅의 넓이나, 일정하지 않은 속도로 움직인 물체의 거리를 구하는 문제에 골몰했다. 직사각형이나 원 같은 정형화된 도형의 넓이는 공식으로 구할 수 있었지만, 곡선으로 둘러싸인 영역은 난공불락의 영역이었다.

적분은 이러한 \*\*'불규칙한 변화의 누적값'\*\*을 구하기 위해 탄생했다.

  * **미분:** $Distance \rightarrow Velocity$ (거리를 미분하면 속도가 된다)
  * **적분:** $Velocity \rightarrow Distance$ (속도를 적분하면 거리가 된다)

즉, 적분은 미분 과정을 거꾸로 거슬러 올라가는 \*\*역연산(Inverse Operation)\*\*의 과정을 수행한다.

### 2.2 기하학적 의미 곡선 아래의 면적

적분을 가장 직관적으로 설명하는 문장은 "함수의 그래프와 x축 사이의 면적을 구하는 것"이다.
수학적으로는 인테그랄($\int$) 기호를 사용하여 표현하며, 이는 'Sum(합)'을 의미하는 'S'를 길게 늘어뜨린 모양에서 유래했다. 이는 무한히 얇은 직사각형들의 합을 의미한다.

## 3\. 핵심 비유 자동차 여행의 재구성

이전 핸드북에서 우리는 자동차 여행을 통해 미분을 배웠다. 이번에는 같은 예시를 적분의 관점에서 재해석하여 두 개념의 관계를 완벽하게 연결한다.

### 3.1 미분의 관점 (복습)

  * **데이터:** 시간에 따른 위치(거리) 그래프
  * **연산:** 미분 (접선의 기울기 계산)
  * **결과:** 시간에 따른 **속도** 그래프

### 3.2 적분의 관점 (새로운 시각)

이번에는 우리에게 주어진 데이터가 \*\*'속도 그래프'\*\*라고 가정해보자. 우리는 이 차량이 총 얼마나 이동했는지 알고 싶다.

| 구분 | 미분 (Differentiation) | 적분 (Integration) |
| :--- | :--- | :--- |
| **입력 데이터** | 위치(거리) vs 시간 그래프 | 속도 vs 시간 그래프 |
| **행동** | 그래프의 **기울기**를 잰다 | 그래프 아래의 **면적**을 칠한다 |
| **산출물** | 속도 (얼마나 빠른가?) | 이동 거리 (얼마나 멀리 갔나?) |
| **핵심 질문** | "지금 이 순간 변화는?" | "지금까지 쌓인 변화의 총합은?" |

### 3.3 왜 면적이 거리가 되는가?

이 원리는 직사각형의 넓이 공식($가로 \times 세로$)에서 출발한다.

  * $속도 \times 시간 = 거리$
  * 속도 그래프에서 \*\*y축은 속도(높이)\*\*이고 \*\*x축은 시간(밑변)\*\*이다.
  * 속도가 일정하다면(직사각형 형태), 단순히 $밑변 \times 높이$가 이동 거리다.
  * 속도가 변하더라도(곡선 형태), 이를 아주 얇은 직사각형들로 쪼개어 합치면(적분), 그 면적의 합은 이동 거리가 된다.

## 4\. 구조 및 심화 이론 미적분의 기본 정리

이 핸드북의 핵심은 적분이 미분의 단순한 반대 과정임을 넘어서, 두 가지가 수학적으로 강력하게 연결되어 있음을 이해하는 것이다. 이를 \*\*미적분학의 기본 정리(Fundamental Theorem of Calculus)\*\*라고 한다.

### 4.1 역연산의 메커니즘

우리가 $x^2$을 미분하면 $2x$가 된다. 반대로 $2x$를 적분하면 $x^2$이 된다.
이는 마치 덧셈과 뺄셈, 곱셈과 나눗셈의 관계와 같다. 머신러닝에서는 모델의 가중치를 업데이트할 때 미분(기울기)을 사용하고, 확률 모델에서 전체 확률의 합을 구할 때 적분을 사용한다.

### 4.2 정적분과 부정적분

강의에서 언급된 "곡선 아래의 영역"은 엄밀히 말해 \*\*정적분(Definite Integral)\*\*이다.

  * **부정적분 (Indefinite Integral):** 미분하기 전의 원래 함수를 찾는 과정 (결과가 함수로 나옴)
  * **정적분 (Definite Integral):** 특정 구간(예: 0분부터 15분까지)에서의 면적 값을 구하는 과정 (결과가 숫자로 나옴)

강의 영상에서 회색으로 칠해진 영역을 계산하는 행위는, 시작 시간($a$)부터 종료 시간($b$)까지 속도 함수를 정적분하여 총 이동 거리를 산출하는 과정이다.

## 5\. 실전 사용법 파이썬을 활용한 적분 구현

개념을 이해했다면, 이를 컴퓨터가 어떻게 계산하는지 알아볼 차례다. Python의 과학 계산 라이브러리인 `SciPy`는 복잡한 적분 계산을 대신해 준다.

### 5.1 수치 적분 (Numerical Integration)

컴퓨터는 곡선을 완벽하게 인식할 수 없으므로, 아주 잘게 쪼갠 사다리꼴이나 직사각형의 합으로 면적을 근사한다. 이를 수치 적분이라고 한다.

```python
import numpy as np
from scipy import integrate

# 예제 함수: 속도 v(t) = t^2 (시간에 따라 가속하는 경우)
def velocity_function(t):
    return t**2

# 0초부터 3초까지 이동한 거리 구하기 (정적분)
# quad 함수는 적분 값과 오차 추정치를 반환한다
distance, error = integrate.quad(velocity_function, 0, 3)

print(f"0초부터 3초까지 이동한 총 거리: {distance:.2f}")
# 계산: (1/3)*3^3 - 0 = 9.0
```

### 5.2 머신러닝에서의 적분 활용

적분은 머신러닝, 특히 확률론적 모델링에서 필수적이다.

1.  **확률 밀도 함수 (PDF):** 정규분포 곡선 아래의 면적은 확률을 의미하며, 전체 면적의 합은 항상 1이다. 이를 계산하기 위해 적분이 사용된다.
2.  **기대값(Expectation) 계산:** 데이터의 평균적인 거동을 예측할 때, 변수와 확률을 곱한 값을 전체 구간에 대해 적분한다.
3.  **손실 함수 평활화:** 때로는 너무 거친 손실 함수를 부드럽게 만들기 위해 적분 개념(평균화)을 도입하기도 한다.

## 6\. 결론 요약 및 향후 학습 로드맵

이번 핸드북에서는 미적분학 1의 미분 파트를 마무리하고, 미적분학 2로 넘어가는 가교로서 적분을 소개했다.

**핵심 요약:**

1.  **적분은 면적이다:** 그래프와 축 사이의 영역을 계산하는 도구다.
2.  **적분은 누적이다:** 변화율(속도)을 모으면 총 변화량(거리)이 된다.
3.  **적분은 역연산이다:** 미분이 대상을 분해하는 것이라면, 적분은 재조립하는 것이다.

이제 여러분은 변화를 분석하는 도구(미분)와 변화를 종합하는 도구(적분)의 개념적 지도를 완성했다. 다음 단계에서는 미적분의 역사적 발전 과정을 통해, 뉴턴과 라이프니츠가 어떻게 이 놀라운 도구를 발견했는지, 그리고 그것이 현대 AI 기술에 어떤 영감을 주었는지 탐구하게 될 것이다. 이는 단순한 수학사를 넘어 기술의 진보를 이해하는 통찰력을 제공할 것이다.

# 아르키메데스의 유산 실진법으로 배우는 미적분의 기원과 무한의 원리

## 1. 서론 4천 년을 관통하는 수학적 직관

우리가 최신 딥러닝 모델을 학습시킬 때 사용하는 수학적 원리는 갑자기 하늘에서 떨어진 것이 아니다. 그것은 수천 년 전, 인류가 '곡선'이라는 자연의 모양을 정복하기 위해 고안해 낸 투쟁의 산물이다.

이 핸드북은 존 크론 박사의 강의를 바탕으로, 미적분학의 전신이라 불리는 **'실진법(Method of Exhaustion)'**을 집중 조명한다. 고대 이집트의 토지 측량에서 시작해 그리스의 기하학을 거쳐, 17세기 미적분학의 정립에 이르기까지, **'무한(Infinity)'**이라는 개념이 어떻게 인류의 가장 강력한 도구인 미적분(Calculus)으로 진화했는지 그 여정을 따라가 본다.

## 2. 미적분학의 역사적 타임라인

### 2.1 라이프니츠 vs 뉴턴
강의에서는 특히 **고트프리트 라이프니츠(Gottfried Leibniz)**의 공헌을 강조한다. 아이작 뉴턴이 미적분을 물리적 현상(행성의 궤도, 중력)을 설명하는 도구로 사용했다면, 라이프니츠는 이를 체계적인 수학적 언어(표기법)로 정리했다. 오늘날 우리가 머신러닝 논문에서 보는 $\frac{dy}{dx}$나 $\int$ 기호는 모두 라이프니츠의 유산이다.

## 3. 핵심 원리 실진법 (Method of Exhaustion)

실진법은 이름 그대로 **"오차를 소진시켜(Exhaust) 없애버리는 방법"**이다. 이는 현대 적분론의 직관적인 모델이자, 극한 개념의 시초다.

### 3.1 다각형 분할의 마법
고대인들은 직선으로 이루어진 도형(사각형, 삼각형)의 넓이는 쉽게 구할 수 있었지만, 원과 같이 굽은 도형의 넓이를 구하는 데 어려움을 겪었다. 실진법의 기본 아이디어는 **"아는 것으로 모르는 것을 채우는 것"**이다.

1.  **복잡한 다각형의 분할:** 육각형과 같은 다각형은 우리가 넓이를 아는 도형(직사각형 1개 + 삼각형 4개)으로 쪼갤 수 있다.
    * 중앙 직사각형: $높이 \times 너비$
    * 상/하단 삼각형: $\frac{1}{2} \times 밑변 \times 높이$
    * 이들의 합이 곧 육각형의 넓이다.

### 3.2 원을 정복하는 전략 근사(Approximation)
이제 이 원리를 원에 적용해 보자. 원 내부에 정다각형을 그려 넣는다.

1.  **정사각형(n=4):** 원 안에 정사각형을 그린다. 원과 정사각형 사이에는 빈 공간(오차)이 많이 남는다. 이는 아주 거친 근사값이다.
2.  **정육각형(n=6):** 변의 수를 늘린다. 빈 공간이 줄어들고, 다각형의 면적이 원의 면적에 더 가까워진다.
3.  **정팔각형(n=8):** 변을 더 늘린다. 오차는 더욱 줄어든다.



### 3.3 무한으로의 도약
여기서 천재적인 발상이 등장한다.
> "만약 다각형의 변의 개수($n$)를 무한대($\infty$)로 늘린다면 어떻게 될까?"

변의 개수가 늘어날수록 다각형은 점점 원에 가까워진다. 이론적으로 변이 무한히 많은 다각형은 원과 구별할 수 없게 된다. 즉, **무한한 변을 가진 정다각형의 넓이 = 원의 넓이**가 되는 것이다. 이것이 바로 적분의 기본 원리이자, 극한($\lim_{n \to \infty}$)의 개념이다.

## 4. 실진법에서 현대 미적분학으로

### 4.1 무한소의 미적분 (Calculus of Infinitesimals)
라이프니츠는 자신이 개발한 이 수학 체계를 '무한소의 미적분'이라고 불렀다.
* **무한소 (Infinitesimal):** 0은 아니지만, 0에 한없이 가까운 아주 작은 양.
* 실진법이 **면적(적분)**을 구하기 위해 도형을 무한히 잘게 쪼개는 과정이었다면, 현대 미적분학은 이 논리를 **기울기(미분)**를 구하는 데에도 적용한다.

### 4.2 현대적 표기법의 승리
뉴턴은 점(dot)을 찍는 방식($\dot{x}$)을 선호했지만, 이는 인쇄하기도 어렵고 변수가 많아지면 헷갈리기 쉬웠다. 반면 라이프니츠의 $d$ 표기법($dx, dy$)은 "x의 아주 작은 변화량"이라는 의미를 직관적으로 전달하며, 분수처럼 연산이 가능해 오늘날 표준이 되었다.

## 5. 머신러닝 엔지니어를 위한 시사점

왜 21세기의 AI 개발자가 2천 년 전의 실진법을 알아야 할까?

### 5.1 최적화의 근본 원리 이해
머신러닝의 학습 과정은 '손실 함수(Loss Function)'의 최소값을 찾는 과정이다. 컴퓨터는 곡선을 완벽하게 이해하지 못한다. 대신 실진법이 원을 다각형으로 근사했듯, 컴퓨터는 곡면을 아주 작은 평면들의 조합으로 근사하여 계산한다. (예: 3D 그래픽의 폴리곤, 수치해석)

### 5.2 극한(Limit)에 대한 직관
다음 장에서 다룰 **미분(Derivative)**은 "두 점 사이의 거리를 0으로 보낼 때($h \to 0$)"의 기울기다. 실진법에서 변의 수를 무한히 늘려 오차를 0으로 만드는 사고방식은, 미분 계수를 정의하는 극한의 사고방식과 정확히 일치한다.

실진법은 단순한 고대의 유물이 아니다. 그것은 "유한한 도구로 무한한 대상을 다루는 방법"을 알려준 인류 최초의 알고리즘이다.

2.  **원리:** 곡선 도형 내부에 다각형을 채워 넣고, 변의 수를 늘려가며 오차를 0으로 만든다.
3.  **진화:** 이 아이디어는 라이프니츠와 뉴턴에 의해 체계화되어 현대 미적분학(Calculus)이 되었다.
4.  **연결:** 실진법의 '무한 접근' 논리는 다음 시간에 배울 **미분(순간 변화율)**의 핵심 기초가 된다.

## 1\. 서론 미분은 '현미경'이다

지난 핸드북에서 우리는 고대 수학자들이 원의 넓이를 구하기 위해 다각형의 변을 무한히 늘려가는 '실진법'을 사용했음을 배웠다. 이것이 적분의 기원이라면, 미분은 정반대의 접근 방식을 취한다.

우리가 멀리서 굽이치는 강을 보면 곡선처럼 보이지만, 강물 바로 위에 떠서 보면 물줄기는 마치 직선처럼 보인다. 미분의 핵심 아이디어인 \*\*'무한소(Infinitesimal)'\*\*가 바로 이것이다. 곡선의 특정 지점을 무한히 확대하면(Zoom in), 그 부분은 결국 **직선**과 구별할 수 없게 된다. 이 직선의 기울기가 바로 그 지점에서의 \*\*미분계수(순간 변화율)\*\*이다.

## 3\. 파이썬 실습 단계별 분석

우리가 관찰할 함수는 $y = x^2 + 2x + 1$ (추정) 형태의 2차 함수다. 이 함수는 $x = -1$에서 최저점을 가지며, 이때 기울기는 0이 되어야 한다. 이를 시각적으로 증명해 보자.

### 3.1 1단계 전체 숲을 보기 (거시적 관점)

먼저 $x$축의 범위를 -10에서 10으로 설정하여 전체 곡선의 모양을 관찰한다.

```python
import numpy as np
import matplotlib.pyplot as plt

# -10에서 10 사이를 1000개의 점으로 쪼갬
x = np.linspace(-10, 10, 1000)
# 함수 정의 (예: y = x^2 + 2x + 1)
y = x**2 + 2*x + 1

plt.plot(x, y)
plt.show()
```

  * **결과:** $U$자 형태의 매끄러운 곡선이 나타난다.
  * **분석:** 이 상태에서는 어느 한 점의 기울기를 직선으로 특정하기 어렵다. 곡선 전체의 휘어짐이 눈에 띄기 때문이다.

### 3.2 2단계 접근 시작 (범위 축소)

관심 지점인 $x = -1$ 근처로 다가가 본다. 범위를 -2에서 0으로 좁힌다.

```python
# 범위를 좁힘 (-2 ~ 0)
x = np.linspace(-2, 0, 1000)
y = x**2 + 2*x + 1

plt.plot(x, y)
plt.xlim(-2, 0) # X축 범위 제한
plt.ylim(0, 2)  # Y축 범위 제한하여 비율 유지
plt.show()
```

  * **결과:** 여전히 곡선처럼 보인다. 바닥 부분이 둥글게 휘어져 있음을 명확히 알 수 있다.

### 3.3 3단계 근접 촬영 (더 깊은 확대)

범위를 -1.5에서 -0.5로 더 좁힌다.

  * **결과:** 곡선의 휘어짐이 완만해지기 시작한다. $U$자의 바닥이 평평해지는 듯한 느낌을 받는다.

### 3.4 4단계 초근접 촬영 (무한소의 영역)

이제 현미경을 들이대듯 범위를 극도로 좁힌다. $x$축의 범위를 -1.01에서 -0.99로 설정한다. 이는 수학적으로 $\Delta x \rightarrow 0$ (델타 x가 0으로 가는) 극한의 상황을 시뮬레이션하는 것이다.

```python
# 아주 미세한 범위 (-1.01 ~ -0.99)
x = np.linspace(-1.01, -0.99, 1000)
y = x**2 + 2*x + 1

plt.plot(x, y)
plt.xlim(-1.01, -0.99)
plt.show() # 결과 확인
```

  * **결과:** **놀랍게도 곡선이 직선처럼 보인다.**
  * **분석:** 이 '직선'은 수평선에 가깝다. 수평선의 기울기는 0이다.
  * **결론:** $x = -1$ 지점에서의 순간 변화율(미분값)은 0이다. 이 지점에서 곡선은 내려가는 것을 멈추고 올라가기 시작하는 변곡점(최소점)이기 때문이다.

## 4\. 이론적 배경 국소 선형성 (Local Linearity)

이 실험이 보여주는 핵심 원리는 \*\*'국소 선형성(Local Linearity)'\*\*이다. 미분 가능한 모든 부드러운 곡선은 아주 작은 구간에서 직선으로 근사(Approximation)할 수 있다.

  * **기하학적 의미:** 우리가 확대한 그 직선이 바로 그 지점에서의 \*\*접선(Tangent Line)\*\*이다.
  * **미분의 정의:**
    $$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
    여기서 $h$를 0으로 보낸다는 것이 바로 우리가 코드로 수행한 '확대(Zoom in)' 과정과 동일하다.

## 5\. 머신러닝과의 연결고리

이 단순해 보이는 '확대' 개념이 왜 머신러닝에서 중요할까?

### 5.1 경사 하강법 (Gradient Descent)의 기초

머신러닝 모델이 학습할 때, 오차(Loss)를 줄이기 위해 파라미터를 조절한다. 이때 "어느 방향으로 움직여야 오차가 줄어드는가?"를 판단해야 한다.

  * 우리는 오차 곡선 위의 한 점에 서 있다.
  * 미분을 통해 그 지점을 무한히 확대하여 **직선의 기울기**를 구한다.
  * 기울기가 0이 되는 지점(평평한 바닥)이 우리가 찾고자 하는 최적의 상태(Minimum Loss)다.
  * 이번 실습에서 $x=-1$일 때 그래프가 수평선(기울기 0)이 되는 것을 확인했다. 즉, 머신러닝 모델은 미분을 통해 기울기가 0인 지점을 찾아내는 탐험가인 셈이다.

# 머신러닝의 두뇌를 깨우는 미적분 현실 세계 적용 가이드

## 1. 서론 추상적인 수학이 현실의 지능이 되기까지

많은 학습자가 "대체 이 복잡한 수학을 어디에 쓰는가?"라는 의문을 품는다. 교과서 속의 미적분은 단순히 그래프의 기울기를 구하거나 넓이를 계산하는 문제 풀이 과정처럼 보인다. 하지만 현실 세계, 특히 인공지능(AI)과 데이터 사이언스 분야에서 미적분은 선택이 아닌 **'생존 도구'**다.

이 핸드북은 존 크론 박사의 강의를 바탕으로, 미적분학이 단순한 이론을 넘어 어떻게 **금융, 공학, 그리고 최첨단 머신러닝 모델**의 심장이 되는지 분석한다. 엔지니어가 다리를 설계할 때 최대 하중을 계산하고, 금융가가 포트폴리오의 비용을 최소화하며, AI가 이미지를 인식하고 게임을 학습하는 모든 과정에 미적분이 숨어 있다. 우리는 이 강력한 도구가 어떻게 '최적화(Optimization)'라는 하나의 목표로 수렴하는지 살펴볼 것이다.

## 2. 미분(Differentiation) 최적화의 나침반

미분의 본질은 **'변화율'**을 파악하여 **'극값(최대/최소)'**을 찾아내는 것이다. 이를 머신러닝에서는 **최적화(Optimization)**라고 부른다.

### 2.1 현실 세계의 일반적 적용
머신러닝 이전에도 미분은 산업 전반에서 핵심적인 의사결정 도구로 사용되었다.
* **공학 (Engineering):** 건축물이나 재료가 버틸 수 있는 **최대 힘(Maximal Strength)**을 계산하여 붕괴를 방지한다.
* **금융 (Finance):** 리스크를 제어하면서 **비용을 최소화(Minimize Cost)**하는 투자 지점을 찾는다.

### 2.2 머신러닝 적용 1 비용 최소화 (Cost Minimization)
지도 학습(Supervised Learning), 특히 딥러닝에서 미분은 '오차를 줄이는 도구'다.

* **비용 함수 (Cost Function):** 모델의 예측값과 실제 정답 사이의 차이(오차)를 수학적으로 정의한 함수다. 우리의 목표는 이 비용을 0에 가깝게 만드는 것이다.
* **경사 하강법 (Gradient Descent):** 비용 함수의 그래프를 산이라고 가정해보자. 미분은 현재 위치에서 **'어느 방향으로 내려가야 가장 가파른지'**를 알려준다.
    * **과정:** 
        1.  임의의 가중치(파라미터)로 시작한다.
        2.  데이터를 넣어 비용(오차)을 계산한다.
        3.  미분을 통해 비용을 줄이는 방향(기울기)을 찾는다.
        4.  그 방향으로 가중치를 조금 수정한다.
        5.  비용이 최소가 될 때까지 반복한다.
* **사례 (손글씨 인식):** 초기 텐서플로(TensorFlow) 모델이 0부터 9까지의 손글씨를 분류할 때, 학습이 반복될수록 비용 곡선은 하강하고 정확도는 상승한다. 미분은 이 '학습의 방향'을 제시한다.

### 2.3 머신러닝 적용 2 보상 최대화 (Reward Maximization)
강화 학습(Reinforcement Learning)에서는 목표가 반대가 된다. 오차를 줄이는 것이 아니라 **점수(보상)를 높이는 것**이 목표다. 이를 **경사 상승법(Gradient Ascent)**이라 한다.

* **심층 Q 러닝 (Deep Q-Learning):** 딥마인드가 아타리 게임을 정복할 때 사용한 알고리즘이다.
* **작동 원리:**
    1.  초기 모델은 게임을 전혀 못 한다 (점수 $\approx$ 0).
    2.  게임 플레이를 통해 보상(점수)을 얻는다.
    3.  보상 함수의 기울기(미분값)를 계산하여, 점수가 **높아지는 방향**으로 파라미터를 업데이트한다.
    4.  수백 번의 에피소드 후, 모델은 만점(예: 200점)에 도달하는 플레이 방식을 스스로 깨우친다.

### 2.4 심화 적용 2차 도함수와 가속도
단순한 기울기(1차 도함수)만 사용하는 것은 비효율적일 때가 있다. 이때 **2차 도함수(Second Derivative)**가 등장한다.

* **가속도의 활용:** 1차 도함수가 속도라면, 2차 도함수는 가속도다. 곡면이 얼마나 급격하게 굽어있는지(Curvature)를 알려준다.
* **팬시 옵티마이저 (Fancy Optimizers):** 뉴턴 메서드(Newton's Method)나 이를 응용한 고급 최적화 알고리즘들은 2차 도함수 정보를 활용하여 학습 속도를 비약적으로 높인다. 평평한 곳에서는 보폭을 크게, 가파르고 좁은 계곡에서는 신중하게 이동하게 해 준다.

## 3. 적분(Integration) 평가와 확률의 척도

미분이 모델을 '학습'시키는 도구라면, 적분은 모델을 '평가'하거나 불확실한 미래를 '예측'하는 데 사용된다. **곡선 아래의 면적(Area Under the Curve)**이라는 기하학적 의미가 머신러닝에서는 **성능의 총합**이나 **확률값**으로 치환된다.

### 3.1 머신러닝 적용 ROC 곡선과 AUC
이진 분류 모델(예: 핫도그인가 아닌가, 암인가 아닌가)의 성능을 평가할 때 단순히 '정확도'만으로는 부족할 때가 있다. 이때 **ROC(Receiver Operating Characteristic) 곡선**을 사용한다.

* **ROC 곡선:** 모델의 민감도(True Positive Rate)와 1-특이도(False Positive Rate) 간의 관계를 그린 곡선이다.
* **AUC (Area Under the Curve):** 이 ROC 곡선 아래의 **면적**을 적분으로 계산한 값이다.
    * **AUC = 1.0:** 완벽한 모델 (모든 정답을 맞힘).
    * **AUC = 0.5:** 동전 던지기와 같은 수준 (찍기).
    * 이 면적을 구하는 과정이 바로 **적분**이다. 모델의 전반적인 신뢰도를 하나의 숫자로 요약해 준다.



### 3.2 확률론 적용 기댓값 (Expectation)
머신러닝의 불확실성을 다루는 '확률론'에서 적분은 필수불가결하다.

* **기댓값 계산:** 연속적인 확률 변수(예: 키, 주식 가격)의 평균을 구할 때, 단순히 더하는 것이 아니라 확률 밀도 함수와 변수를 곱한 값을 전체 구간에 대해 **적분**한다.
    $$E[X] = \int_{-\infty}^{\infty} x f(x) dx$$
* 이는 머신러닝 기초 시리즈의 5번째 과목인 '확률론과 정보론'의 핵심 기초가 된다.

# 파이썬으로 정복하는 극한(Limits) 계산 불가능을 계산하다

## 1\. 서론 극한, 미적분의 시작점

미분과 적분을 이해하기 위해서는 반드시 \*\*'극한(Limit)'\*\*이라는 관문을 통과해야 한다. 극한은 "도달할 수는 없지만, 한없이 가까워지는 상태"를 수학적으로 정의한 것이다. 머신러닝에서 미분(기울기)을 구할 때 $h \to 0$으로 보내는 과정이 바로 극한이다.

이 핸드북은 존 크론 박사의 강의를 바탕으로, 종이와 펜으로 풀던 극한 문제를 **파이썬 코드**로 해결하는 방법을 다룬다. 특히 $0$으로 나누는 것과 같이 수학적으로 '금지된' 연산을 극한을 통해 어떻게 우회하고 해석하는지 집중적으로 탐구한다.

## 2\. 연속 함수 vs 불연속 함수

### 2.1 연속 함수 (Continuous Function)

그래프를 그릴 때 펜을 떼지 않고 한 번에 그릴 수 있는 함수다.

  * **특징:** 끊어진 구간이나 구멍이 없다.
  * **극한 계산법:** $x$가 $a$에 가까워질 때의 극한값은 단순히 함수에 $a$를 대입한 값($f(a)$)과 같다.
    $$\lim_{x \to 5} (x^2 + 2x + 2) = 5^2 + 2(5) + 2 = 37$$
  * **파이썬 구현:** `def`로 함수를 정의하고 값을 넣으면 끝이다.

### 2.2 불연속 함수 (Discontinuous Function)

특정 지점에서 값이 정의되지 않거나 그래프가 끊어지는 함수다. 미적분학의 재미는 여기서 시작된다.

  * **대표 예시:** $f(x) = \frac{x^2 - 1}{x - 1}$
  * **문제점:** $x=1$을 대입하면 분모가 0이 되어 계산이 불가능하다 ($\frac{0}{0}$ 꼴).
  * **해결책:** $x$가 1은 아니지만, 1에 아주 가까운 수를 대입하여 경향성을 파악한다.

## 3\. 극한 계산의 3가지 접근법

우리는 $x=1$에서 정의되지 않는 함수 $f(x) = \frac{x^2 - 1}{x - 1}$의 극한값을 구하기 위해 다음 세 가지 방법을 사용할 수 있다.

### 3.1 접근법 1 수치 대입 (Numerical Method) - 파이썬 활용

파이썬을 이용해 $x$에 1에 매우 가까운 값을 대입해 본다.

```python
def f(x):
    return (x**2 - 1) / (x - 1)

# 왼쪽에서 접근 (1보다 약간 작은 수)
print(f(0.9))      # 1.9
print(f(0.999))    # 1.999

# 오른쪽에서 접근 (1보다 약간 큰 수)
print(f(1.1))      # 2.1
print(f(1.001))    # 2.001
```

  * **결론:** $x$가 1에 가까워질수록 $y$는 **2**에 가까워진다. 따라서 극한값은 2다.

### 3.2 접근법 2 대수적 풀이 (Algebraic Method) - 인수분해

수학 공식(인수분해)을 이용해 식을 약분한다.
$$\frac{x^2 - 1}{x - 1} = \frac{(x-1)(x+1)}{x-1} = x + 1$$

  * 약분 후 $x=1$을 대입하면 $1+1=2$가 나온다.
  * **장점:** 정확한 값을 빠르게 구할 수 있다.
  * **단점:** $\frac{\sin x}{x}$처럼 인수분해가 불가능한 식에는 사용할 수 없다.

### 3.3 접근법 3 그래프 시각화 (Graphical Method)

함수의 그래프를 그려 눈으로 확인한다.

  * Matplotlib으로 그리면 $x=1$ 지점에서 매끄럽게 이어지는 직선($y=x+1$)처럼 보인다.
  * 엄밀하게는 $x=1$ 지점에 \*\*구멍(Hole)\*\*이 뚫려 있어야 한다.

## 4\. 파이썬 실습 까다로운 극한 정복하기

### 4.1 삼각함수의 극한 ($\lim_{x \to 0} \frac{\sin x}{x}$)

이 함수는 인수분해가 불가능하며, $x=0$에서 계산되지 않는다.

```python
import numpy as np

def sin_x_over_x(x):
    return np.sin(x) / x

# x=0 대입 시 오류 발생 (ZeroDivisionError 또는 RuntimeWarning)
# 0에 가까운 수 대입
print(sin_x_over_x(0.00001)) # 0.999999... -> 1에 수렴
```

### 4.2 무한대로 가는 극한 ($\lim_{x \to \infty} \frac{25}{x}$)

$x$가 계속 커질 때 함수가 어디로 가는지를 본다.

  * $x=10 \rightarrow y=2.5$
  * $x=1000 \rightarrow y=0.025$
  * $x=10^6 \rightarrow y=0.000025$
  * **결론:** $x$가 무한대로 가면 $y$는 **0**에 수렴한다.

### 4.3 불연속 그래프 그리기 꿀팁 (Matplotlib)

$y = \frac{25}{x}$와 같은 유리함수는 $x=0$에서 끊어져 있다. 이를 그대로 `plt.plot(x, y)`로 그리면, 파이썬은 $x=0$ 근처의 양수와 음수를 억지로 연결해 버려 이상한 수직선이 생긴다.

**해결 방법:** 데이터를 끊어진 구간을 기준으로 두 개로 나누어 그린다.

```python
import matplotlib.pyplot as plt
import numpy as np

# 데이터를 0을 기준으로 나눔
x_left = np.linspace(-10, -0.1, 100)
x_right = np.linspace(0.1, 10, 100)

y_left = 25 / x_left
y_right = 25 / x_right

# 색상을 통일하여 하나의 함수처럼 보이게 함
plt.plot(x_left, y_left, color='blue')
plt.plot(x_right, y_right, color='blue')
plt.show()
```

# 미적분학의 기초 극한 실전 문제 풀이와 완벽 해설 가이드

## 1\. 서론 이론을 넘어 실전으로

이전 섹션들에서 우리는 극한(Limit)이 무엇인지, 그리고 그것이 머신러닝의 학습 곡선과 어떤 관계가 있는지 시각적으로 확인했다. 하지만 눈으로 보고 이해하는 것과 손으로 직접 풀어내는 것은 전혀 다른 영역이다. 머신러닝 논문을 읽거나 알고리즘의 수렴성을 증명할 때, 극한은 더 이상 직관적인 그래프가 아닌 차가운 수식으로 다가온다.

이 핸드북은 존 크론 박사의 강의에서 제시된 5가지 핵심 연습 문제를 심층 분석한다. 단순한 대입부터 인수분해, 그리고 좌극한과 우극한의 개념까지, 미적분학 1(Calculus 1)을 지탱하는 연산의 뼈대를 튼튼히 하는 것이 목표다. 이 과정을 통해 여러분은 "0으로 나눌 수 없다"는 수학의 금기를 깨고, 변화의 순간을 포착하는 능력을 갖추게 될 것이다.

## 2\. 문제 풀이의 3가지 핵심 전략

문제를 풀기 전, 극한 문제를 마주했을 때 사용할 수 있는 무기들을 정리해 보자.

| 전략 | 설명 | 사용 시기 | 대표 예시 |
| :--- | :--- | :--- | :--- |
| **1. 직접 대입 (Direct Substitution)** | $x$에 목표값을 그냥 넣는다. | 함수가 연속이고 분모가 0이 아닐 때 | $\lim_{x \to 2} (x+3)$ |
| **2. 인수분해 (Factoring)** | 식을 변형하여 약분한다. | $\frac{0}{0}$ 꼴 (부정형)이 나올 때 | $\lim_{x \to 1} \frac{x^2-1}{x-1}$ |
| **3. 수치적/직관적 접근** | 값을 아주 조금씩 변화시키며 경향을 본다. | 인수분해가 안 되거나 무한대로 갈 때 | $\lim_{x \to \infty} \frac{1}{x}$ |

## 3\. 실전 문제 분석 및 해설

다음 5가지 문제는 미적분학에서 마주칠 수 있는 가장 대표적인 상황들을 담고 있다.

### 문제 1: 함정 없는 연속 함수

**질문:** 다음 극한값을 구하시오.
$$\lim_{x \to 0} \frac{x^2 - 1}{x - 1}$$

**[1단계: 전략 수립]**
극한 문제의 첫 번째 규칙은 언제나 \*\*'일단 대입해 보는 것'\*\*이다. $x=0$을 식에 넣었을 때 분모가 0이 되는지 확인한다.

**[2단계: 풀이 과정]**

  * 분자: $0^2 - 1 = -1$
  * 분모: $0 - 1 = -1$
  * 결과: $\frac{-1}{-1} = 1$

**[3단계: 해설]**
이 함수는 $x=1$에서는 불연속이지만, 우리가 구하려는 $x=0$ 지점에서는 완벽하게 연속이다. 따라서 복잡한 기교 없이 대입만으로 답을 구할 수 있다.
**정답: 1**

-----

### 문제 2: 0분의 0꼴과 합차 공식

**질문:** 다음 극한값을 구하시오.
$$\lim_{x \to -5} \frac{x^2 - 25}{x + 5}$$

**[1단계: 전략 수립]**
$x = -5$를 대입해 본다.

  * 분자: $(-5)^2 - 25 = 25 - 25 = 0$
  * 분모: $-5 + 5 = 0$
  * 결과: $\frac{0}{0}$ (부정형)
    계산 불능 상태다. 이는 그래프 상에 \*\*'구멍(Removable Discontinuity)'\*\*이 뚫려 있음을 의미한다. 식을 변형해야 한다.

**[2단계: 대수적 풀이 (인수분해)]**
분자의 $x^2 - 25$는 전형적인 '제곱의 차' 형태다. $a^2 - b^2 = (a-b)(a+b)$ 공식을 적용한다.

$$\lim_{x \to -5} \frac{(x-5)(x+5)}{x+5}$$

이제 분자, 분모의 공통 인수인 $(x+5)$를 약분하여 제거한다. 문제의 원흉인 '0이 되는 요소'가 사라졌다.

$$\lim_{x \to -5} (x - 5)$$

이제 대입이 가능하다.
$$-5 - 5 = -10$$

**[3단계: 파이썬 검증]**
인수분해가 어렵다면 코드로 값을 근사할 수 있다.

```python
def f(x):
    return (x**2 - 25) / (x + 5)

print(f(-4.9999)) # -9.9999 -> -10에 수렴
```

**정답: -10**

-----

### 문제 3: 2차식의 인수분해

**질문:** 다음 극한값을 구하시오.
$$\lim_{x \to 4} \frac{x^2 - 2x - 8}{x - 4}$$

**[1단계: 전략 수립]**
$x=4$를 대입하면 분모가 $4-4=0$이 된다. 분자도 $16-8-8=0$이다. 역시 $\frac{0}{0}$ 꼴이다. 인수분해가 필요하다.

**[2단계: 대수적 풀이]**
분자 $x^2 - 2x - 8$을 인수분해해야 한다.

  * 곱해서 -8, 더해서 -2가 되는 두 수를 찾는다. (-4, 2)
  * 분자: $(x-4)(x+2)$

식을 다시 쓴다.
$$\lim_{x \to 4} \frac{(x-4)(x+2)}{x-4}$$

$(x-4)$를 약분한다.
$$\lim_{x \to 4} (x + 2)$$

대입한다.
$$4 + 2 = 6$$

**정답: 6**

-----

### 문제 4: 음의 무한대로의 발산

**질문:** 다음 극한값을 구하시오.
$$\lim_{x \to -\infty} \frac{25}{x}$$

**[1단계: 전략 수립]**
이번엔 특정 숫자가 아닌 무한대($\infty$) 문제다. $x$가 음의 방향으로 끝없이 커질 때(예: -10억), 분수의 값이 어디로 가는지 묻는 것이다.

**[2단계: 직관적 해석]**
분자(25)는 고정되어 있는데 분모($x$)의 절대값이 엄청나게 커진다. 피자 25판을 전 인류가 나눠 먹는다고 상상해 보라. 1인당 돌아가는 양은 거의 0에 가깝다. 부호가 음수(-)이므로 0보다 아주 조금 작은 수(음의 0)로 수렴하겠지만, 극한값 자체는 0이다.

**[3단계: 파이썬 검증]**

```python
x = -1e9 # -10억
print(25 / x) # -0.000000025 -> 0
```

**정답: 0**

-----

### 문제 5: 좌극한과 우극한의 불일치

**질문:** 다음 극한값을 구하시오.
$$\lim_{x \to 0} \frac{25}{x}$$

**[1단계: 전략 수립]**
$x=0$을 대입하면 분모가 0이 된다. 하지만 문제 2, 3번과 달리 **약분할 수 있는 인수가 없다.** 이는 그래프가 이어지지 않고 찢어져 있음을 시사한다.

**[2단계: 방향별 분석]**
0으로 다가가는 방법은 두 가지다. 오른쪽(양수)에서 오는 것과 왼쪽(음수)에서 오는 것.

1.  **우극한 ($\lim_{x \to 0^+}$):**

      * $x$는 양수 (예: 0.0001)
      * $\frac{25}{0.0001} = 250,000$
      * $x$가 작아질수록 값은 \*\*양의 무한대($+\infty$)\*\*로 폭발한다.

2.  **좌극한 ($\lim_{x \to 0^-}$):**

      * $x$는 음수 (예: -0.0001)
      * $\frac{25}{-0.0001} = -250,000$
      * $x$가 작아질수록 값은 \*\*음의 무한대($-\infty$)\*\*로 추락한다.

**[3단계: 해설 및 표기법]**
이 경우 "극한값이 존재하지 않는다"라고 말하거나, 방향에 따라 따로 표기해야 한다.

  * $\lim_{x \to 0^+} \frac{25}{x} = \infty$
  * $\lim_{x \to 0^-} \frac{25}{x} = -\infty$

**정답: 우극한은 $\infty$, 좌극한은 $-\infty$**

## 4\. 심화 이론 파이썬 `SymPy`로 자동화하기

지금까지 손으로 푼 문제들을 파이썬의 기호 수학 라이브러리인 `SymPy`를 사용하면 한 줄로 해결할 수 있다. 이는 복잡한 머신러닝 수식을 다룰 때 매우 유용하다.

```python
import sympy as sp

x = sp.symbols('x')

# 문제 2번 자동 풀이
expr2 = (x**2 - 25) / (x + 5)
limit2 = sp.limit(expr2, x, -5)
print(f"문제 2 정답: {limit2}") # -10

# 문제 5번 (우극한) 자동 풀이
expr5 = 25 / x
limit5_right = sp.limit(expr5, x, 0, dir='+') # dir='+'는 우극한
print(f"문제 5 우극한: {limit5_right}") # oo (infinity)
```

## 5\. 결론 및 요약

이 5개의 문제는 단순해 보이지만 미적분학의 핵심 쟁점들을 모두 관통하고 있다.

1.  **연속성:** 문제가 없으면 그냥 대입하라. (문제 1)
2.  **부정형 해결:** 0/0 꼴은 인수분해를 통해 '범인(0이 되는 항)'을 제거하라. (문제 2, 3)
3.  **무한소와 무한대:** 분모가 무한히 커지면 전체는 0이 되고(문제 4), 분모가 무한히 작아지면 전체는 무한대로 발산한다(문제 5).

이 개념들은 다음 장에서 다룰 \*\*'미분(Derivatives)'\*\*의 정의인 $\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$를 이해하는 데 결정적인 역할을 한다. 미분 공식 자체가 바로 이 '0분의 0' 꼴 극한을 계산하는 과정이기 때문이다. 이제 여러분은 변화율을 계산할 준비가 완벽하게 끝났다.
