# 07. 극한 계산하기 (Calculating Limits)

> **"0으로 나눌 수 없을 때, 우리는 극한을 구한다"**

이번 장에서는 미분의 기초가 되는 **극한(Limits)**을 계산하는 다양한 방법(대입, 인수분해, 수치적 접근)을 배웁니다.

---

## 1️⃣ 연속 함수의 극한 (Continuous Functions)

함수가 매끄럽게 연결되어 있는(끊어짐이나 뾰족한 점이 없는) **연속 함수**의 경우, 극한을 구하는 것은 매우 쉽습니다.

### 예제: $f(x) = x^2 + 2x + 2$

$x$가 5에 가까워질 때의 극한값은?

$$
\lim_{x \to 5} (x^2 + 2x + 2)
$$

연속 함수에서는 **직접 대입**하면 됩니다:

$$
5^2 + 2(5) + 2 = 25 + 10 + 2 = 37
$$

**결론**: $\lim_{x \to 5} f(x) = 37$

---

## 2️⃣ 불연속 함수의 극한 (Discontinuous Functions)

분모가 0이 되는 경우처럼, 함수값이 정의되지 않는 지점에서의 극한은 어떻게 구할까요?

### 예제: $f(x) = \frac{x^2 - 1}{x - 1}$

$x$가 1에 가까워질 때의 극한값은?

$$
\lim_{x \to 1} \frac{x^2 - 1}{x - 1}
$$

**직접 대입 시도**:

$$
\frac{1^2 - 1}{1 - 1} = \frac{0}{0} \quad (\text{정의되지 않음!})
$$

### 방법 1: 수치적 접근 (Numerical Approach)

$x$를 1에 아주 가깝게 만들면서 $y$값의 변화를 관찰합니다.

| $x$ (좌극한) | $y$          | &nbsp; | $x$ (우극한) | $y$          |
| :----------- | :----------- | :----- | :----------- | :----------- |
| 0.9          | 1.9          |        | 1.1          | 2.1          |
| 0.99         | 1.99         |        | 1.01         | 2.01         |
| 0.999        | 1.999        |        | 1.001        | 2.001        |
| $\downarrow$ | $\downarrow$ |        | $\downarrow$ | $\downarrow$ |
| **1**        | **2**        |        | **1**        | **2**        |

**결론**: $\lim_{x \to 1} f(x) = 2$

### 방법 2: 대수적 접근 (Algebraic Approach - 인수분해)

분자를 인수분해하여 식을 정리합니다.

$$
\frac{x^2 - 1}{x - 1} = \frac{(x-1)(x+1)}{x-1}
$$

$x \neq 1$이라는 가정하에 약분하면:

$$
\lim_{x \to 1} (x + 1) = 1 + 1 = 2
$$

## 3️⃣ 특수한 극한: $\frac{\sin x}{x}$와 무한대

### 예제: $f(x) = \frac{\sin x}{x}$

$x \to 0$일 때의 극한은? (대수적으로 풀기 어려움)

**수치적 접근 코드**:

```python
import numpy as np

def f(x):
    return np.sin(x) / x

print(f(0.1))    # 0.9983...
print(f(0.001))  # 0.9999998...
print(f(-0.001)) # 0.9999998...
```

**결론**: $\lim_{x \to 0} \frac{\sin x}{x} = 1$

> **참고**: 그래프에서 정의되지 않는 $x=0$ 지점은 보통 '빈 원(Hollow Circle)'으로 표시합니다.

### 예제: $f(x) = \frac{25}{x}$ (무한대로 가는 극한)

$x \to \infty$일 때의 극한은?

$$
\lim_{x \to \infty} \frac{25}{x}
$$

$x$가 커질수록 분모가 커지므로 값은 0에 가까워집니다.

```python
def f(x):
    return 25 / x

print(f(1000))  # 0.025
print(f(1e6))   # 0.000025
```

**결론**: $\lim_{x \to \infty} \frac{25}{x} = 0$

---

## 🎯 요약

1. **연속 함수**: 극한값 = 함수값 (직접 대입).
2. **0/0 꼴**:
   - **수치적 접근**: 좌극한/우극한 값을 대입해보며 추론.
   - **대수적 접근**: 인수분해 후 약분.
3. **무한대 극한**: 분모가 무한히 커지면 전체 값은 0에 수렴.

이것으로 미적분학 I의 첫 번째 파트인 **극한(Limits)**이 완료되었습니다. 다음 장부터는 이 극한을 사용하여 **도함수(Derivatives)**를 계산하는 본격적인 미분의 세계로 들어갑니다!
