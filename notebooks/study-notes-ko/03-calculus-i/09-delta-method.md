# 09. 델타 방법 (The Delta Method)

> **"두 점 사이의 기울기를 이용해 접선의 기울기를 찾다"**

이번 장에서는 미분(도함수)을 시각적, 수치적으로 이해하는 가장 기초적인 방법인 **델타 방법(Delta Method)**을 배웁니다.
우리는 극한(Limit)을 사용하여 할선(Secant Line)이 어떻게 접선(Tangent Line)으로 변하는지 파이썬 코드로 확인해 봅니다.

---

## 1️⃣ 핵심 원리: 평균 변화율에서 순간 변화율로

곡선 위의 한 점 $P$에서의 기울기(접선)를 구하고 싶습니다.

1. **점 $P$와 가까운 점 $Q$를 선택합니다.**
   - 두 점 사이의 직선의 기울기($m$)를 구합니다.
   - 이것은 **평균 변화율**입니다.
2. **점 $Q$를 점 $P$에 점점 가깝게 이동시킵니다.**
   - 두 점 사이의 거리($\Delta x$)가 줄어듭니다.
3. **$\Delta x \to 0$이 되면 (극한)**:
   - 두 점을 잇는 직선은 점 $P$에서의 **접선**과 같아집니다.
   - 이때의 기울기가 바로 **순간 변화율(미분계수)**입니다.

$$
m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1} \quad \xrightarrow{\Delta x \to 0} \quad \text{도함수 (Derivative)}
$$

---

## 2️⃣ 파이썬 실습: 델타 방법 구현

함수 $y = x^2 + 2x + 2$에서 $x=2$일 때의 기울기를 구해봅시다.

### 2.1 기초 설정 및 점 P

```python
import numpy as np
import matplotlib.pyplot as plt

def f(x):
    return x**2 + 2*x + 2

# 점 P 설정 (기준점)
x1 = 2
y1 = f(x1)  # 2^2 + 2*2 + 2 = 10
print(f"점 P: ({x1}, {y1})")
```

### 2.2 멀리 떨어진 점 Q와의 기울기 및 직선 그리기

점 $Q$가 $x=5$에 있다고 가정해 봅시다.

```python
# 점 Q 설정
x2 = 5
y2 = f(x2)  # 5^2 + 2*5 + 2 = 37
print(f"점 Q: ({x2}, {y2})")

# 1. 기울기 m 계산 (평균 변화율)
m = (y2 - y1) / (x2 - x1)
print(f"기울기 m: {m}")  # (37-10)/3 = 9

# 2. y절편 b 계산 (y = mx + b -> b = y - mx)
# 점 Q(5, 37)를 대입
b = y2 - m * x2
print(f"y절편 b: {b}")  # 37 - 9*5 = -8

# 직선의 방정식: y = 9x - 8
```

이 직선은 곡선을 뚫고 지나가는 **할선**입니다.

### 2.3 점 Q를 P에 가깝게 이동 ($x=2.1$)

점 $Q$를 $x=2.1$ 위치로 옮겨봅시다 ($\Delta x = 0.1$).

```python
x2 = 2.1
y2 = f(x2)  # 10.61

m = (y2 - y1) / (x2 - x1)
b = y2 - m * x2

print(f"새로운 기울기 m: {m}")  # 6.1
print(f"새로운 절편 b: {b}")    # -2.2
```

기울기가 9에서 **6.1**로 줄어들었습니다.

### 2.4 점 Q를 아주 가깝게 이동 ($\Delta x \to 0$)

$\Delta x$를 매우 작게($10^{-6}$) 설정하여 극한을 시뮬레이션합니다.

```python
delta_x = 1e-6
x2 = x1 + delta_x
y2 = f(x2)

m = (y2 - y1) / (x2 - x1)
print(f"극한 기울기 m: {m}")  # 약 6.000001
```

**결론**: $\Delta x$가 0에 가까워질수록 기울기는 **6**에 수렴합니다.
따라서 $x=2$에서의 순간 변화율(접선의 기울기)은 **6**이고, 접선의 방정식은 $y = 6x - 2$(추정)가 됩니다.

## 📝 연습 문제 (직접 해보기)

2. $\Delta x$를 매우 작게 설정 (예: $1e-6$)
3. $x_2 = x_1 + \Delta x$ 계산
4. 기울기 $m = \frac{f(x_2) - f(x_1)}{x_2 - x_1}$ 계산
